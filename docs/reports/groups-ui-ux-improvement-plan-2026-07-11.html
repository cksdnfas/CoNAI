Frontend / UI·UX review

CoNAI 그룹 페이지 개선 계획

폴더 계층 인지, 탐색 밀도, 그룹 카드 구분, 모바일 흐름을 중심으로 한 구현 전 검토안

검토 기준: 2026-07-11 대상: 커스텀 그룹 · 감시폴더 그룹 문서 성격: 구현 전 계획서

요약

핵심은 그룹 화면을 “이미지 카드 모음”이 아니라 “폴더를 탐색하고 그 안의 이미지를 보는 화면”으로 다시 읽히게 만드는 것이다.

현재 화면은 좌측 트리, 브레드크럼, 상위 이동 카드, 하위 그룹 카드가 같은 탐색 기능을 반복한다. 반면 그룹 카드는 미리보기 이미지 비중이 커서 폴더인지 이미지 앨범인지 구분이 약하고, 커스텀 그룹의 주요 작업은 사이드바 아이콘 안에 숨어 있다. 제안안은 상단 경로를 한 줄로 축소하고, 폴더 카드를 항상 폴더처럼 보이게 하며, 그룹 정보·작업·이미지 필터를 각각 한 위치로 통합한다.

1순위
탐색 요소 중복 제거와 경로 축소
2순위
폴더 카드 정체성·정보 위계 강화
3순위
모바일·상태·용어 일관성 마감

현재 화면에서 확인된 문제

탐색과 계층

  • 데스크톱에는 좌측 트리, 브레드크럼, 상위 이동 카드가 동시에 나타나 같은 이동 경로를 세 번 제공한다.
  • 상위 이동 카드가 실제 하위 폴더 카드와 같은 그리드에 섞여 현재 위치와 콘텐츠의 구분이 약하다.
  • 브레드크럼은 감시폴더·데스크톱에서만 보이고 커스텀 그룹과 모바일에서는 사라져 소스에 따라 탐색 규칙이 달라진다.
  • 모바일에서 탐색기가 본문 위에 최대 화면 높이 30%의 sticky 영역으로 남아 이미지까지 도달하는 데 스크롤 부담이 크다.

폴더 카드와 정보 인지

  • 미리보기 이미지가 있으면 폴더 아이콘이 사라져 카드가 이미지 카드처럼 보인다.
  • media-tile은 세로형 이미지 비중이 커서 폴더보다 갤러리 항목으로 인식되기 쉽다.
  • 카드에 이미지 수는 있지만 하위 폴더 수, 비어 있음, 현재 선택 상태가 충분히 구분되지 않는다.
  • 이미지와 하위 항목이 없는 그룹은 카드와 트리에서 이동이 제한되어 빈 커스텀 폴더를 열어 편집하거나 하위 폴더를 만드는 흐름이 끊긴다.

작업 위치와 발견성

  • 커스텀 그룹 선택 시 상세 헤더가 생략되고 다운로드·편집이 좌측 탐색기 아이콘에만 노출된다.
  • 그룹 생성, 전체 자동 수집, 편집, 다운로드가 사이드바·상세 카드·선택 바에 흩어져 있다.
  • 아이콘 버튼은 툴팁 전까지 뜻을 알기 어렵고 모바일에서는 hover 설명을 사용할 수 없다.
  • 현재 그룹 이름과 주요 작업이 콘텐츠 시작점에서 항상 함께 보이지 않는다.

표현과 피드백

  • 한국어 화면에 Groups, manual, auto가 섞여 있다.
  • 이미지 영역에 표시 수, 로드 수, 전체 수, 필터 수가 여러 줄로 반복돼 핵심 콘텐츠보다 상태 정보가 먼저 보인다.
  • 루트·하위 그룹 로딩 스켈레톤과 빈 상태가 실제 카드 구조를 충분히 설명하지 않는다.
  • 카드 스타일 설정이 두 종류지만 폴더 인지 규칙은 공통으로 보장되지 않는다.

제안 화면 구조

상단의 큰 폴더 이동 영역을 한 줄 경로 바로 줄이고, 탐색·현재 그룹·이미지 도구의 역할을 분리한다.

핵심 변경안

1. 경로 바 축소
브레드크럼과 상위 이동 카드를 하나의 36~40px 경로 바로 통합한다. 데스크톱은 전체 경로, 모바일은 뒤로가기 + 현재 폴더명만 표시한다. 긴 경로는 가로 스크롤 또는 앞부분 생략을 사용한다.
2. 폴더 카드 재설계
기본은 낮은 높이의 가로 카드로 바꾸고 폴더 아이콘을 항상 노출한다. 미리보기는 보조 썸네일로만 사용한다. 이름, 이미지 수, 하위 폴더 수를 한눈에 읽게 하고 빈 폴더도 열 수 있게 한다.
3. 그룹 헤더 통합
커스텀·감시폴더 모두 같은 슬림 헤더를 사용한다. 현재 그룹명과 핵심 수치를 왼쪽, 다운로드·추가·더보기 작업을 오른쪽에 둔다. 상세 메타데이터는 접힌 영역으로 유지한다.
4. 탐색기 단순화
데스크톱 트리는 유지하되 선택·빈 폴더 이동 규칙을 카드와 통일한다. 모바일에서는 sticky 패널 대신 “폴더 탐색” 버튼으로 drawer를 열어 본문 높이를 확보한다.
5. 이미지 도구 통합
제목, 전체 수, 전체/직접 추가/자동 수집 필터, 열 수 조절을 한 줄 도구 바로 묶는다. 표시/로드/숨김 상세는 로딩 중이거나 실제 차이가 있을 때만 보인다.

폴더 카드 규격

권장 기본형

  • 높이 72~88px의 가로형 카드.
  • 왼쪽에 고정 폴더 아이콘, 필요하면 40~48px 미리보기 썸네일을 함께 배치.
  • 1행: 폴더명, 2행: 이미지 수 · 하위 폴더 수.
  • 오른쪽 화살표는 이동 가능성을 표현하고, 선택 상태는 테두리·배경으로 구분.
  • 빈 폴더는 비활성화하지 않고 “비어 있음” 상태를 표시.

미디어형 유지 조건

  • 사용자 설정의 미디어형 옵션은 유지하되 세로 5:6 대신 낮은 가로 비율을 권장.
  • 미리보기 위에도 폴더 아이콘 또는 “폴더” 배지를 항상 표시.
  • 이미지와 폴더 카드가 같은 화면에서 혼동되지 않도록 모서리, 오버레이, 메타데이터 배치를 구분.
  • 미리보기 실패·없음 상태에서도 카드 크기와 텍스트 위치가 변하지 않게 고정.

진행 단계

1
탐색 구조 정리
공통 경로 바 도입, 상위 이동 카드 제거, 커스텀/감시폴더의 현재 위치 표현 통일. 기존 API와 라우팅은 변경하지 않는다.
2
폴더 카드와 트리 정비
가로형 폴더 카드, 고정 폴더 아이콘, 이미지·하위 폴더 수, 빈 폴더 이동 규칙을 적용하고 트리와 일치시킨다.
3
그룹 헤더·작업 통합
두 소스의 그룹 헤더를 통합하고 생성·편집·다운로드·자동 수집의 위치와 노출 조건을 정리한다.
4
이미지 영역 밀도 축소
필터, 수치, 열 수 조절, 진행 상태를 한 도구 바로 합치고 반복 정보를 조건부로 표시한다.
5
반응형·접근성·회귀 검증
모바일 drawer, 키보드 탐색, 포커스, 긴 이름, 빈/오류/로딩, 이미지 선택·다운로드 흐름을 검증한다.

완료 기준

  • 상단 경로 영역이 한 줄 높이로 유지되고 상위 이동용 대형 카드가 사라진다.
  • 미리보기 유무와 관계없이 모든 그룹 카드가 폴더임을 즉시 알아볼 수 있다.
  • 모든 폴더 카드에서 이름, 이미지 수, 하위 폴더 수 또는 빈 상태를 확인할 수 있다.
  • 빈 커스텀 폴더를 열어 편집하거나 하위 폴더를 추가할 수 있다.
  • 커스텀 그룹과 감시폴더 그룹이 같은 현재 위치·뒤로가기 규칙을 사용한다.
  • 모바일 첫 화면에서 탐색기가 본문을 계속 밀어내지 않고 drawer로 열고 닫힌다.
  • 그룹 생성·편집·다운로드·자동 수집 작업의 위치와 권한 규칙이 일관된다.
  • 한국어 화면에 노출되는 “Groups / manual / auto” 혼용이 정리된다.
  • 기존 이미지 무한 스크롤, 열 수 설정, 선택·이동·제거·다운로드 기능이 유지된다.
  • 데스크톱·태블릿·모바일에서 긴 폴더명, 깊은 계층, 빈 목록, 로딩, 오류 상태가 깨지지 않는다.

포함하지 않을 일

  • 그룹 API, 데이터베이스 계층, 자동 수집 규칙 자체의 변경.
  • 이미지 카드와 상세 모달의 전면 재설계.
  • 드래그 앤 드롭으로 그룹 계층을 바꾸는 신규 기능.
  • 그룹 검색, 정렬, 즐겨찾기 같은 신규 탐색 기능. 기본 구조 정비 후 필요성을 다시 판단한다.

구현 전 결정할 항목

  1. 카드 기본값: 단순성과 폴더 인지를 위해 가로형 폴더 카드를 기본으로 권장한다. 미디어형은 사용자 선택 옵션으로 유지한다.
  2. 모바일 탐색 방식: 기존 공통 drawer를 재사용할 수 있으면 drawer, 없으면 접히는 전체 화면 패널을 사용한다.
  3. 그룹 작업 노출: 자주 쓰는 “하위 그룹 추가”는 직접 노출하고, 편집·자동 수집·삭제는 더보기 메뉴로 묶는 구성이 가장 단순하다.
