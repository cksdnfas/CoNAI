# Release Notes

## Version 26.10.10 (2026-10-10)

v26.10.10은 26.9.29 이후 352개 커밋을 묶은 릴리즈입니다. 앱 안에서 쓰는 **채팅**, 효과음을 만들고 다듬는 **오디오** 작업실, 영상을 스프라이트 시트로 만드는 **스프라이트** 도구가 새로 들어왔습니다. **LLM 연결** 구조도 크게 바뀌었습니다. 기존 연결과 워크플로우 노드는 처음 시작할 때 자동으로 옮겨집니다.

---

### 채팅

- 헤더의 채팅 아이콘으로 어느 페이지에서든 오른쪽 패널로 열고, 전체 화면(`/#/chat`)으로도 사용
- 프로필마다 엔진 선택: **Codex**, **Claude Code**, **API LLM**(OpenAI 호환·Ollama, 로컬 엔진 포함)
- 채팅 프로필: 캐릭터 설정, 아바타, 꾸미기, 한 답변에 여러 인물 등장, 캐릭터 카드 가져오기
- 그룹 방: 여러 프로필이 `@이름`으로 불리거나 판단 모델이 다음 화자를 골라 답변
- 로어북, 장기 기억과 자동 요약, 작성자 노트, 상태·표시 블록
- 로어북 키 언어: 영어 키에 언어 하나(한·일·중 등)를 더 두고 함께 매칭, 빠진 키 채우기, 재귀 스캔(깊이 0~5)
- 기록용 로어북: 채팅마다 로어를 저장할 계정 로어북을 지정하고, 모델이 로어 파일에 이어 쓰기
- 연결 파일: 파일 보관함의 파일·폴더를 채팅·프로필에 연결하면 모델이 찾아 읽고 쓰기
- Claude Code 채팅은 세션을 이어 가고(그룹 방은 멤버별), 앱 도구는 목록에서 찾아 쓰는 방식으로 정리
- 대화 중 NovelAI·ComfyUI·Codex 이미지 생성(Codex는 생성 탭과 같은 큐로 접수), 라이브러리 이미지·영상 첨부, 파일 붙여넣기·끌어놓기
- 생성 프리셋별 프롬프트 작성 시점(답변 중·답변 뒤), 작성 가이드, 이전 이미지 참고(0~4장)
- 한 답변의 여러 이미지는 메이슨리로 표시
- 답변 안에서 바로 실행하는 지시: 그리기, 다시 그리기, 음성, 로어 저장, 선택지
- 페이지 연결: 보고 있는 화면을 읽고 입력을 채우거나 워크플로우를 편집, 저장은 확인 카드로 승인
- 번역(모델 언어·표시 언어, 코드 블록은 번역하지 않음), 답장 추천, 재생성·편집·답변 분기, 검색·내보내기
- 루틴: 정해진 시간에 채팅방을 깨우는 자동화
- 허용 등급: 모델에게 보여 줄 미디어의 등급 상한 지정

- **유지보수**: DB 통계·온라인 백업·압축, 고아 파일 정리, RecycleBin 복구

### LLM 모델 연결 (바뀐 점)

LLM 연결은 **설정 › LLM** 탭에서 관리합니다. "연결 = 어느 서버", "프로필 = 어떻게 부를지"로 역할이 나뉘었습니다.

- **서버 ▸ 모델 구조**
  - 연결 하나가 서버 하나이고, 쓰는 모델이 연결 아래 줄로 붙습니다.
  - 연결 편집 창에서 서버가 알려 주는 모델 목록을 체크해 추가합니다. 목록을 주지 않는 서버는 모델 ID를 직접 입력합니다.
  - 모델 줄마다 사용처(프로필·판단·워크플로우 노드 등)가 표시되고, 쓰는 곳이 있는 모델과 연결은 지울 수 없습니다.
  - 모델 ID를 바꾸면 그 줄을 쓰는 프로필·판단·노드가 모두 따라 바뀝니다.
  - 기본 모델(★) 하나가 새 프로필과 모델이 없는 프로필에 쓰입니다.
- **연결 종류**: OpenAI 호환, Ollama, TypeSafe 판단 모델
- **연결 설정**: 주소, API 키, 요청 제한 시간, 동시 요청 수, 생각 끄는 방법, 프롬프트 캐시 표시
- **생성 옵션은 프로필로 이동**
  - 온도·최대 출력 토큰은 이제 연결이 아니라 프로필(또는 워크플로우 노드)에서 정합니다.
  - 추론 강도(none~high)·추론 토큰 예산·추가 요청 파라미터(JSON)도 프로필에서 정합니다.
  - 비운 옵션은 요청에 넣지 않습니다.
  - 최대 출력 토큰은 상한입니다. 컨텍스트에 남은 자리가 그보다 적으면 남은 만큼만 요청합니다.
  - 토큰 입력칸은 `260K`처럼 줄여 쓴 값도 받습니다.
- **역할별 모델**: 프로필마다 대화·요약·번역·답장 추천·판단 모델을 따로 고를 수 있습니다.
- **연결 테스트**: 생각 끄는 방법이 실제로 먹히는지 확인하고, 안 되면 되는 방법으로 바꿔 둡니다.
- **자동 대응**
  - 서버가 알려 주는 컨텍스트 길이를 읽어서 사용합니다.
  - 도구를 못 받는 모델은 도구 없이 다시 보냅니다.
  - LiteLLM·OpenRouter 경유 Anthropic 모델에는 프롬프트 캐시 표시를 붙입니다.
  - 같은 연결에서는 답변에 필요한 요청이 뒷정리 요청보다 먼저 서버를 씁니다.
- **CLI 관리**: Codex·Claude Code의 설치·로그인·업데이트 상태와 구독 사용 한도·초기화 시간을 같은 탭에서 확인합니다.
- **사용량 대시보드**: LLM 호출 기록과 판단 로그·답변 진단을 설정 › LLM에서 봅니다.
- **워크플로우 LLM 호출 노드**: 연결 이름 대신 모델 줄이나 채팅 프로필을 고릅니다.

#### 기존 설정 이전

- 연결에 저장돼 있던 기본 모델은 그 연결 아래 모델 줄이 됩니다. 원래 쓰던 서버와 모델을 그대로 씁니다.
- 연결의 온도·최대 토큰 값은 그 연결을 쓰던 프로필의 빈 칸으로 옮겨지고, 연결에서는 빠집니다.
- 저장된 워크플로우의 LLM 호출 노드는 같은 연결·모델의 모델 줄을 가리키도록 바뀝니다(없으면 새로 만듭니다).
- 연결이 사라진 노드는 그대로 두며, 이전과 같이 실행에 실패합니다.

### 업그레이드 참고

- **26.8.x 이하에서는 바로 올릴 수 없습니다.** 이전 마이그레이션(001~035)을 하나의 기준 마이그레이션으로 합쳤기 때문입니다. 26.9.29로 한 번 실행해 DB를 올린 뒤 업데이트하세요.
- 시작 시 DB 마이그레이션 `037`~`043`이 자동 적용됩니다.
  - `040`(자동 태그 인덱스)과 `041`(미디어 메타데이터 테이블)은 테이블을 다시 만듭니다.
  - 라이브러리가 크면 첫 시작이 오래 걸릴 수 있으니 미리 DB를 백업해 두세요.
- **권한 체계 변경**
  - 권한이 18개 기능 키(보기·수정·삭제)로 정리됐고, 페이지 접근은 기능 권한에서 자동으로 정해집니다.
  - 처음 시작할 때 기존 권한 그룹이 새 키로 한 번 변환되고, 변환 전후 권한이 로그에 남습니다.
  - 익명 그룹에 있던 회원 전용 권한은 게스트 그룹으로 옮겨집니다. 로그인하지 않은 방문자에게는 이미지 보기와 게스트 가입만 남습니다.
- Docker 이미지에 Codex CLI와 Claude Code CLI가 포함됩니다. 로그인 정보는 데이터 폴더의 `codex/`·`claude/`에 저장됩니다.
- MCP 서버가 MCP SDK v2(스펙 2026-07-28)로 올라갔습니다. 이전 스펙 클라이언트도 그대로 붙습니다. 권한 때문에 숨겨진 도구를 부르면 이제 도구 오류 결과 대신 JSON-RPC 오류(`-32602`)가 돌아갑니다.
- Civitai 게시물 업로드 기능은 제거됐습니다.
- Node.js **20.19 이상**이 필요합니다.
