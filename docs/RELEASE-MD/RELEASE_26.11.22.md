# Release Notes

## Version 26.11.22 (2026-11-22)

v26.11.22는 26.11.05 이후 66개 커밋을 묶은 릴리즈입니다. 함께 배포하는 **공식 플러그인**(MOSS BBox Studio·Video Canvas·HyperFrames), 플러그인 페이지의 **공용 공유와 선언 범위 권한**, 채팅의 **대화별 모델·입력 도구**, 캐릭터 화면의 **그림 스타일·RefMod**가 중심입니다.

---

### 플러그인

- **공식 플러그인 3종 포함**: MOSS BBox Studio 1.1.3, Video Canvas 1.5.2, HyperFrames 영상 제작 1.5.2. 처음 시작할 때 꺼진 채 설치되며 켜기·끄기만 가능
- 공식 플러그인 업데이트 적용 여부(업데이트됨 칩·이전 버전) 표시, 실패 알림과 재시작 없이 다시 적용
- **공용 페이지 공유**: 플러그인 페이지를 `/public/ext/…` 공용 페이지로 공개하고 링크 복사·접근 현황 확인
- **선언 범위 권한**: 공용 페이지 방문자에게 플러그인이 선언한 도구·API·기능만 빌려줌. 삭제·관리자 전용·LLM 기능은 제외
- 플러그인 목록 행에 공용 페이지 수와 멈춘 공유 다시 공개 버튼, 이미지 상세에서 플러그인으로 이미지 넘기기

---

### 채팅

- **대화별·그룹 멤버별 모델 지정**: 프로필을 바꾸지 않고 다른 모델로 답변, 헤더 칩에 사용 모델 표시
- 사용 중인 프로필도 **엔진 변경** 가능: 대화는 메시지·요약을 유지한 채 새 엔진으로 전환
- **입력창 + 메뉴**: 생성 프리셋·도구 지정, 나레이션 키, 터치 화면 Enter 줄바꿈. 생성 프리셋에 Codex 추가, 목록 밖 값·빈 입력은 큐 등록 전에 거절
- 답변에 적용된 **로어 개수 칩**, 파일 보관함의 **채팅에 참조**, 채팅이 보관 이미지와 메타데이터 읽기
- **토큰 절감**: pi의 Anthropic 프롬프트 캐시, 페이지 도구는 바뀐 부분만 전송, MCP 도구 설명 축약
- 채팅방별 응답 스트림 분리, 이미지 권한 없는 계정의 채팅 이미지 상세·참조, 번역 누락·복사 버튼·재생성 오류 수정

---

### 캐릭터·그림 스타일·RefMod

- **그림 스타일**: 참고 이미지·긍정/부정 프롬프트 저장, 즐겨찾기·복제·ZIP 가져오기·내보내기, 생성 폼에서 불러오기
- **RefMod**: CoNAI에서 만든 RefMod를 원본과 함께 관리, ZIP 이전, 서버 파일 존재 표시
- 스타일·RefMod가 쓰는 파일은 파일 보관함에서 삭제·덮어쓰기 차단, 채팅·MCP 도구 추가

---

### 생성·워크플로우

- **MiniMax H3 Director** 프롬프트를 한 칸으로 통합, 활성 RefMod 없는 `<RefMod N>` 생성 전 차단
- **SnapRef** 노드 전용 입력(참조 1~8장·강도·모드)
- 워크플로 지정 필드의 기본값 드롭다운·ComfyUI 선택지 가져오기·숨김 필드, 오디오·비디오 입력
- 모델 자동수집 경로 확장(vae·text_encoders·clip_vision·controlnet·upscale_models)
- 결과 줄 페이지 단위 이동, 워크플로 입력 한글 파일명·공용 워크플로 H3 첨부 403 수정

---

### 이미지·파일·UI

- 레이아웃 프롬프트를 영역별 칩으로 표시하고 영역 맵에서 강조
- 파일 보관함 강제 종료 시 중단된 쓰기 복구, AV1 디코딩 시 시스템 FFmpeg 사용
- 접근성: 본문 건너뛰기, 포커스 이동·복귀, 모션 줄이기, 라이트 모드 대비. 이미지 상세 단축키와 한글 자판 단축키
- 홈 검색 정리, 떠 있는 메뉴 레이어 정리, 화면 밖 영상 해제·숨김 탭 폴링 정지

---

### 업그레이드 전 확인

- **DB**: 047 마이그레이션과 새 채팅 모델 열·RefMod·그림 스타일 테이블이 자동으로 적용됩니다. 예전 라이브러리 이미지를 쓰던 그림 스타일은 시작 직후 한 번 파일 보관함 사본으로 바뀝니다.
- **Docker**: 기본 이미지에 Chromium·Noto 한글/이모지 폰트·tini가 추가됐습니다(HyperFrames 렌더). 이미지를 다시 빌드하세요.
- **MiniMax H3 Director**: 구조화 탭이 없어지고 예전 칸 내용은 소제목 붙은 글 하나로 합쳐집니다. MCP의 구조화 섹션 키와 그래프의 예전 구조화 포트 연결은 오류로 거절됩니다.
- **프로필 엔진 변경**: 저장하면 해당 대화들의 엔진 세션과 대화별 모델 지정이 초기화되고, 답변 중인 대화가 있으면 저장이 거절됩니다.
- **플러그인**: 매니페스트에 `capabilities`(media.read·media.save·media.pick·jobs)와 `appRoutes`가 추가됐습니다. 공용 페이지는 업데이트로 선언이 바뀌면 다시 공개할 때까지 권한 대여가 멈춥니다. Video Canvas 생성 설정은 계정 공용 라이브러리로 자동 이관됩니다.
- **파일 보관함**: 그림 스타일·RefMod 원본 파일은 삭제·덮어쓰기가 거절됩니다. 예전에 깨져 저장된 한글 파일명은 표시할 때만 복원됩니다.
- 채팅 미디어(`/api/codex-chat/media`)는 `images.view` 대신 채팅 접근만 요구합니다.
