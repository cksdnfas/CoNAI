# Release Notes

## Version 26.11.05 (2026-11-05)

v26.11.05는 26.10.10 이후 162개 커밋을 묶은 릴리즈입니다. 화면 작업과 다른 프로필에게 일을 맡기는 **채팅 어시스턴트**, 외형과 참고 이미지를 재사용하는 **캐릭터 라이브러리**, 자유롭게 꾸미는 **월페이퍼**, 설명으로 찾고 레이어로 다듬는 **이미지 검색·편집**이 중심입니다. 공용 파일·프로젝트, 게시판 지식 평가와 플러그인도 함께 확장됐습니다.

---

### 채팅

- **페이지 연결 확대**: 생성·이미지 상세·그룹·프롬프트·와일드카드·파일·게시판·오디오·스프라이트·월페이퍼·설정·플러그인에서 조회와 입력뿐 아니라 실행·저장·삭제까지 지원 범위 확대
- 화면의 저장·삭제·생성은 검토 카드로 확인하고, 카드에는 실제 대상·입력·비용을 표시. 이동한 화면에 맞춰 도구를 갱신하고, 공개 화면에서 시작한 답변은 비공개 화면을 조작하지 않음
- **프로필 에이전트**: 다른 프로필에 비동기로 일을 맡기고 원래 대화에서 결과·생성 이미지를 받기. 작업방은 **자동화 → 에이전트**에 모으며 결과 알림만 받거나 결과를 보고 대화를 이어가도록 선택
- **스킬**: 여러 프로필이 공통 지시를 연결해 사용. 개요·섹션 목차부터 읽고 필요한 섹션만 불러오며, 키워드·의미 검색, 기록 비교·복원, Agent Skills ZIP·`SKILL.md` 가져오기·내보내기 지원
- **프로필 위임 권한**: 관리자가 사용자에게 직접 열지 않을 이미지 조회·생성 등의 기능을 특정 프로필에만 허용. 해당 대화에서 실제로 찾거나 생성한 이미지는 라이브러리 권한 없이도 확인
- 모든 프로필에서 **웹 검색 담당**으로 지정한 Codex·Claude Code에 웹 조사를 맡기고 출처 확인. 공개 웹 문서 읽기, 계정별 하루 검색 한도, 연결 폴더에 검색 결과 저장
- 외부 MCP 서버(stdio·HTTP)를 연결하고 프로필별 도구 목록에서 선택
- API LLM의 **실행 방식**에 **pi 에이전트** 추가: 같은 연결·모델로 세션 기억과 자동 압축 사용. 선택적으로 **pi codemode**를 켜 여러 앱 도구를 한 번에 호출
- 프로필 프롬프트를 **지시문 → 예시 → 실제 대화** 순서로 편집. **시작 대화**를 새 채팅의 실제 메시지로 넣고, 인사말 위치·다른 인사말을 함께 관리
- 사용자 메시지에서 `$`로 시작하는 줄을 나레이션으로 구분
- 프로필 폴더·폴더 안 끌어 정렬·복사, 대화 자동 제목·날짜별 목록, 여러 대화 보관·삭제·가져오기, 방별 알림 켜기·끄기
- 같은 계정 로어북이나 연결 파일을 공유하는 대화의 기록 검색·읽기, 쓰기 연결한 폴더에 **회의록** 이어 쓰기
- 그룹방도 담당 멤버별 작업 계획 실행. 작업 예산을 늘려 재개하고, 승인 카드·생성 작업의 실제 완료 대상에 맞춰 대기·재개
- 로어북 의미 검색·언어별 본문, 포함 그룹의 재귀 단계별 선택, **선택 로어 상위 개수** 설정. 로어 번역 시 정규식 키·추가 언어 키 보존
- 선택지·추천 답변도 표시 언어로 번역. 짧은 입력·괄호 지시·재생성·이어쓰기의 번역 누락 수정
- 연결 불가 프로필에 상태와 이유를 표시하고 보내기 전에 다시 확인. 답변 오류 옆 재시도, 작업 단계·예산 승인·컨텍스트 상태를 한 줄로 정리
- 표시 블록 필드의 **표시 이름**, 답변 진단·대화별 사용량, 세션을 이어갈 때 바뀐 작가 노트·사용자 정보·상태의 최신 값 반영

### LLM 연결과 모델 설정

- **대표모델**: 대화·요약·번역·답장 추천·판단마다 대상 모델과 기본 프롬프트·허용 등급을 지정하고, 이름 붙인 대표모델도 추가
- 프로필·판단 프리셋·워크플로우가 대표모델을 고르면 대상 모델을 바꿔도 같은 대표모델을 계속 사용
- **최대 컨텍스트**는 프로필 설정과 서버가 알려 준 크기 중 작은 값 사용. 임의의 문맥 크기·출력 상한 대신 프로필·연결 설정을 따르며, 크기를 모르는 pi는 자동 압축을 끔
- Claude Code의 추론 토큰 예산 지원. Codex·Claude Code·pi의 1:1 세션 압축과 별도 요약·외형 초안용 보조 모델을 구분해 표시
- **도구 호출 반복 한도**를 설정 → 채팅 → 도구 사용에서 직접 API·pi·Claude Code 공통으로 관리(기본 50회, Codex 제외). 본문으로 새어 나온 지원 형식의 도구 호출도 제공된 도구·권한 안에서 실행
- 요약·판단의 반복 출력 감지, 요약 실패 후 재시도 간격 조절, 도구 결과가 문맥을 채우면 오래된 결과부터 줄여 답변 마무리
- CLI 상태·설치 버전·업데이트와 구독 사용량 표시 보강, Claude 인증 만료 시 상태 새로고침으로 갱신 시도, 내장 pi 런타임 업데이트

### 캐릭터 라이브러리

- **캐릭터 → 외형 라이브러리**: 작품·캐릭터별 폴더에 외형 태그·의상·기준 이미지·아바타·표정·생성 후보 보관
- 정체성·머리·눈·얼굴·체형 등 항목별 태그와 이름 붙인 의상. Danbooru 캐릭터, 기준 이미지 자동 태그 또는 AI 초안으로 채우기
- **캐릭터 카탈로그**에서 작품별 Danbooru 캐릭터·샘플을 보고 외형 설정으로 가져오기
- 태그·한글 이름 검색, 항목별 필터와 개수, 즐겨찾기, 여러 설정 이동·내보내기·삭제, 목록 무한 스크롤과 상세 창의 이전·다음 탐색
- **참고 이미지** 갤러리에 설정화·포즈·의상·소품을 직접 만든 분류로 정리하고, 생성 폼에 여러 장 선택해 불러오기
- 채팅 프로필에 외형 설정을 연결해 동기화하거나 독립 사본으로 분리. 동기화 외형을 고치면 연결된 프로필도 함께 바뀌며, 설정 삭제 시 현재 외형을 프로필에 복사해 보존
- NAI·ComfyUI·Codex 생성 폼과 워크플로우 **생성 프리셋** 노드에서 외형·의상 사용
- 외형 설정과 기준·아바타·표정·후보 이미지를 ZIP으로 가져오기·내보내기. 기준 이미지가 없어도 외형 태그로 기준·표정 후보 생성(이미지 입력 필수 ComfyUI 워크플로는 제외)

- **최근 대화·채팅** 위젯에 앱의 실제 채팅 패널 사용: 이미지·첨부·검토 카드·메뉴·스트리밍을 그대로 이용
- 위젯별 카드·유리·외곽선, 색·글꼴·강조색·등장 효과와 **크기 배율**. 배경은 색·그라데이션·라이브러리 이미지·영상·그룹 슬라이드쇼로 구성

- Lively·Wallpaper Engine용 패키지와 실행 키 발급·폐기. 호스트 오디오 시각화·재생 중 정보·일시 정지 연동, 관리자용 시스템 모니터와 예약 워크플로 바로 실행
- 요일·시간별 프리셋 일정, 위젯 표시 시간, 낮·밤 테마, 파티클·시차·배경 이동·포인터 근처 표시·FPS 제한
- 실시간 이벤트로 위젯 갱신, 숨김·호스트 일시 정지 시 애니메이션 중단, Wallpaper Engine의 실행 키 연결 오류 수정

### 이미지·검색·그룹

- 라이브러리 검색의 **설명** 탭: 한국어·영어 문장으로 그림 내용을 찾고 뜻이 가까운 순서와 일치 점수 표시. 기존 등급·모델·프롬프트 조건과 함께 사용
- 이미지 상세에 **내용 유사·화풍 유사** 추가. 이미지 임베딩과 Kaloscope 화풍 벡터로 각각 검색
- **갤러리 옵션 → 그룹 숨기기**: 선택한 그룹과 하위 그룹을 홈 목록·검색·전체 수에서 제외하고 스위치로 잠시 해제. 브라우저별 설정이며 다른 페이지의 접근을 막는 기능은 아님
- 검색 기록에 모델·LoRA·생성 도구 칩과 필터 조건 보존
- **이미지 편집기 개편**: 레이어, 브러시·지우개·필압, 사각·올가미 선택, 선택 픽셀 이동·복사·채우기, 편집 가능한 텍스트
- 밝기·대비·채도·색상·색온도 보정, 비율 자르기·크기 변경·회전·뒤집기, 원본 비교·확대율 프리셋·단축키 목록
- **AI 지우기**: 지울 곳을 모아 칠한 뒤 실행하고 별도 레이어로 결과 확인. 저장 옵션을 취소해도 편집은 남으며, 저장본은 원본을 바꾸지 않고 라이브러리와 원본의 커스텀 그룹에 추가
- 삭제 보호가 켜진 이미지 삭제 알림에 **되돌리기** 제공. 같은 위치의 새 파일을 덮어쓰지 않고 복원
- 그룹 관리에서 여러 그룹 이동·삭제, 트리 우클릭 메뉴, 같은 이름의 하위 그룹까지 확인 후 재귀 병합
- 그룹에 오디오·작업 문서 연결, 하위 그룹을 포함한 ZIP 다운로드와 중복 파일명·캡션 처리
- 가중치 괄호·쉼표가 섞인 태그의 표시·수집·검색 규칙 정리, 이미지 메타데이터 동시 저장 충돌 검사

### 워크플로우·프롬프트·생성

- 프롬프트의 랜덤 소스를 칩으로 편집: 와일드카드, Danbooru 태그 그룹 `__tag:그룹__`, 내 프롬프트 그룹 `__my:그룹__`
- `@`·`__`·Ctrl+Space 통합 선택창, 선택 개수·사용량 조건·미리 뽑기, 최근 사용·관련 태그 추천과 키보드 탐색. 기존 문법은 유지하며 변환 버튼 제공
- ComfyUI의 일반 편집기 workflow JSON을 API 형식으로 변환해 가져오기·저장. 이미지·영상에 들어 있는 워크플로를 드롭해 불러오기
- ComfyUI 서버별 누락 노드·모델·값 검사, 추천 Marked Field, 자동 배치와 출력에 연결되지 않은 노드 표시
- ComfyUI의 `seed`·`noise_seed`는 실행마다 새로 뽑고, Marked Field 지정값이나 원본의 `fixed` 설정은 유지
- 워크플로우 노드를 대표 항목과 변형으로 묶고, 호환되는 입력·연결을 유지한 채 변형 전환. 기존 워크플로우는 그대로 열고 실행
- NAI·Codex·ComfyUI·워크플로와 공개 워크플로, 스프라이트·오디오·이미지 상세·업로드 검사에 블록 레이아웃과 공용 프리셋 적용. 관리자가 열·폭·순서·숨김을 편집하고 각자 프리셋 선택
- **NovelAI**: V5 Full Medium (Economy), 품질 태그·UC 프리셋, 반복 생성과 전체 예상 비용, V5 Opus 사용량·인페인트 강도·모델 판별 보강
- NovelAI img2img에 **인핸스** 1x·1.5x·Max 추가. 지원 크기·비용을 표시하고 결과는 서버가 돌려준 크기로 저장
- **Codex**: 원본과 별개로 역할·설명을 붙인 참조 이미지 추가. **엄격 마스크 보존**은 원본 크기와 보호 영역 픽셀을 유지한 PNG로 저장
- 생성 중에도 사용자가 고른 결과·이력 화면을 유지하고, 예약 편집·재개와 워크플로 저장 충돌 시 초안 보존
- **공개 워크플로우**는 로그인한 계정이 일반 생성·갤러리 권한 없이도 큐에 넣고 자기 실행 결과 확인. 워크플로별 등급 한도와 결과 접근 범위는 유지

### 게시판·지식

- 게시글을 **지식 문서**로 지정하고 검증됨·재검토 필요·미검토 상태로 관리
- 사람의 추천·오류 제보, 지식을 사용한 AI의 평가, 판단모델 평가를 구분하고 문서 버전·근거와 연결
- 출처·참조·역참조, 수정 제안·문서 초안, 검토 요청, 지식 휴지통·복원·내보내기. **문서 정보**에서 평가·검토·연결·변경 제안을 모아 확인

### 업그레이드 참고

- **Node.js 22.13.0 이상**이 필요합니다. 이전 릴리즈의 20.19 이상 안내보다 요구 버전이 올라갔습니다.
- **26.8.x 이하에서는 바로 올릴 수 없습니다.** 먼저 26.9.29로 실행해 기준 DB로 올린 뒤 업데이트하세요.
- 시작 시 DB 마이그레이션 `044`~`046`이 자동 적용됩니다.
  - `044`는 미디어 메타데이터 상태 열·인덱스와 영상 최적화 작업 테이블, `045`는 그룹 연결 자료 테이블, `046`은 프롬프트 3종의 그룹별 정렬 인덱스를 추가합니다. 이 세 마이그레이션은 기존 테이블을 다시 만들지 않습니다.
  - 기존 미완료 미디어 상태 갱신과 인덱스 생성 때문에 대형 라이브러리는 첫 시작이 길어질 수 있습니다. 업데이트 전에 DB를 백업해 두세요.
  - 중간 alphatest의 단일 프로젝트 연결은 여러 프로젝트 연결로 자동 이전하며, 기존 `workspace_bindings`가 있으면 연결 테이블을 다시 만들어 복사합니다.
- **파일 보관함은 계정별이 아니라 공용입니다.** 기존 계정별 소유권·폴더 구분이 없어집니다. 같은 위치의 이름 충돌은 이전 항목에 구분 접미사를 붙이고 파일 ID·첨부 참조는 유지합니다. 다른 계정에게 보이면 안 되는 자료를 먼저 확인하세요.
- **새 채팅 첨부는 개인 전용이지만 이전 공용 첨부는 자동 이동하지 않습니다.** 개인 첨부를 사용한 방은 공용 파일함의 백업·진단 저장·회의록 자동 저장이 막히고 로어 저장은 검토 카드로 바뀝니다.
  - JSON·Markdown 내보내기에는 첨부 원본이 없습니다. 마지막 참조 메시지·대화를 지우면 첨부도 사용할 수 없으니 원본을 먼저 다운로드하세요. 보내지 않은 파일은 24시간 뒤 만료됩니다.
  - 개인 첨부를 썼던 **게시판 · 봇** 방은 게시판 호출이 막힙니다. 필요한 기록·원본을 내려받고 그 방 자체를 삭제하면 다음 호출이 새 방을 만듭니다. 공개 페이지에서는 개인 첨부를 쓰지 않은 별도 채팅을 사용하세요.
- **백업 범위 확대**: DB와 함께 `user/uploads`·`user/files`·`user/workspaces`를 같은 시점으로 보관하세요. 설치한 플러그인의 `user/plugins`도 DB와 함께 보존해야 합니다. 설정의 DB 백업에는 파일 원본·프로젝트·패키지가 들어가지 않습니다.
- **모델 설정 이전**: 기존 ★·⚖ 기본 모델은 대화·판단 대표모델로 옮겨지고, 해당 기본 모델을 사용하던 프로필·프리셋·워크플로 참조도 대표모델로 바뀝니다. 실제 연결·모델은 유지합니다.
- **생성 가이드 이전**: 파일함 문서를 연결했던 생성 프리셋은 문서를 공유 스킬의 섹션으로 자동 이전합니다. 읽을 수 없는 문서는 연결이 풀리므로 **가이드 스킬**을 확인하세요. 이전의 미리 넣은 기록도 시작 대화로 옮기며, 옮길 수 없는 묶음은 예시로 남습니다.
- **AI 환경 변경**: 기존 ONNX 태거 대신 통합 PyTorch 워커를 사용합니다. 설정 → 자동 분석의 **AI 런타임**에서 설치 상태를 확인하고, 직접 지정한 Python은 새 의존성에 맞춰야 합니다. Kaloscope v2 결과 재추출과 임베딩 최초 모델 다운로드·색인은 오래 걸릴 수 있으며 임베딩은 기본 꺼짐입니다.
- **Docker GPU 빌드 변경**: `PYTORCH_CUDA_INDEX_URL` 대신 `TORCH_BACKEND`(Compose는 `CONAI_TORCH_BACKEND`)를 사용합니다. 기본 `cu130`은 RTX 20 이상·드라이버 580 이상, GTX 900/1000·V100 또는 드라이버 560 이상 환경은 `cu126`을 선택하세요. 기본 이미지는 계속 CPU 전용입니다.
- **플러그인은 신뢰된 앱 코드입니다.** 화면은 같은 origin에서 계정의 API를, 서버 모듈은 파일·네트워크·프로세스를 사용할 수 있습니다. 별도 기능 허용 목록이나 격리 실행으로 여기지 말고 신뢰하는 패키지만 설치하세요. Docker 소켓을 연결하면 앱과 모든 서버 플러그인에 호스트 Docker 관리자 권한을 줍니다.
- **권한 변경**: 캐릭터 라이브러리는 `characters.view`·`characters.edit`, 웹 검색은 `chat.web.use`를 사용합니다. 프로필 위임은 기본 없음이며 사용자 자신의 페이지·API·외부 MCP 키 권한을 늘리지 않습니다. 공개 워크플로우는 로그인과 등급별 한도로 이용을 허용하며, 아티팩트 탐색 폴더는 이용자들이 함께 봅니다. 공개 설정과 폴더 내용을 다시 확인하세요.
