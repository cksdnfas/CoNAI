# CoNAI 가이드

CoNAI는 이미지·영상·생성물 관리를 기반으로 지식을 축적하고 작업을 자동화하는 개인화 앱입니다. 혼자 또는 소수 사용자가 사용하는 환경을 중심으로, 미디어 관리와 채팅 어시스턴트·지식·자동화의 사용법을 안내합니다.

릴리즈 노트는 별도 섹션에서 유지합니다: [릴리즈 노트](/RELEASE-MD/)
