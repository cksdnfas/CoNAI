# 캐릭터 라이브러리

캐릭터의 외형을 한 번 등록해 이미지 생성이나 채팅 프로필에서 다시 쓰는 기능입니다. 대화 성격·모델을 가진 채팅 프로필과 달리, 라이브러리의 **외형 설정**은 이미지 프롬프트용 태그와 그림을 보관합니다. 채팅과 외형 라이브러리는 서로 독립된 기능입니다. 채팅 없이 라이브러리를 쓰거나, 라이브러리 연결 없이 프로필로 대화할 수 있습니다.

## 관련 페이지

| 목적 | 경로 |
| --- | --- |
| 외형 라이브러리 | `/characters` |
| 캐릭터 카탈로그 | `/characters?view=catalog` |
| 채팅 프로필 연결 | `/chat/profiles` → 프로필 편집 → 외형 (설정 안에서는 `/settings?section=chat&profile=<id\|new>`) |
| 이미지 생성에 불러오기 | `/generation` → NAI / Codex / ComfyUI |
| 워크플로우에서 사용 | `/generation?tab=workflows` → 생성 프리셋 노드 |

상단의 **캐릭터**(기본 고정 페이지, 휴대폰은 하단 탭)로 이동합니다. 고정을 풀었다면 **라이브러리** 메뉴에 있습니다. 어디에도 없으면 `characters.view` 권한을 확인합니다.

캐릭터 페이지에는 **외형 라이브러리 · 캐릭터 카탈로그**만 있습니다. 카탈로그는 `prompts.view` 권한이 있을 때 전환에 나타납니다. `/characters?setting=12`처럼 특정 외형 설정을 상세 창으로 여는 주소도 사용할 수 있습니다. 채팅 프로필은 **채팅 → 프로필**, 페르소나·플래그는 **채팅 → 내 설정** 또는 **설정 → 내 설정 → 페르소나·플래그**, 프리셋·표시 블록·로어북은 **채팅 → 자원**에서 관리합니다. 관리자는 **설정 → 채팅** 안에서도 프로필과 자원을 편집할 수 있습니다.

## 폴더와 외형 설정

<a id="채팅-프로필-탭"></a>

### 채팅 프로필과 폴더

관리자의 **채팅 → 프로필**(`/chat/profiles`)도 같은 폴더 사이드바·경로·검색·3:4 카드 목록을 사용하지만 캐릭터 페이지와는 별개입니다. 프로필 폴더와 외형 폴더도 별개입니다. **새 폴더**로 만들고 폴더 메뉴에서 이름 변경·이동·삭제를 할 수 있습니다. **프로필 폴더를 삭제해도 프로필은 지워지지 않습니다.** 안의 프로필과 하위 폴더는 삭제한 폴더의 부모로 옮겨집니다. 부모에 같은 이름의 폴더가 있으면 삭제가 취소되므로 먼저 이름을 바꾸세요.

카드는 연결된 외형의 기준 이미지, 연결이 없으면 프로필 아바타를 표시합니다. 꺼진 프로필은 흐리게 표시되며 모델·도구와 연결 문제도 확인할 수 있습니다. 우클릭·길게 누르기 또는 카드의 작업 버튼으로 편집·복사·폴더 이동·켜기/끄기를 실행합니다. 같은 폴더의 카드를 끌어 순서를 바꾸면 채팅 선택기에도 반영됩니다. 검색 중에는 순서 변경 대신 폴더를 먼저 여세요.

**새 프로필**, 복사, 캐릭터 카드 가져오기는 현재 폴더에 초안을 만들며 편집기의 **프로필 폴더**에서 바꿀 수 있습니다. 검색 중 새 항목과 새 폴더는 최상위에 만듭니다. 빈 새 프로필은 폴더만 지정되어 있어도 미저장 변경으로 표시하지 않습니다. 검색은 모든 프로필 이름을 찾습니다. `/chat/profiles` 주소의 `folder`, `q`, `page`, `profile`이 탐색 위치와 열린 편집기를 보존합니다(`profile=<id|new>`). 다른 폴더로 옮긴 프로필은 그 폴더의 맨 뒤에 붙습니다. 폴더를 지워 부모로 올라온 프로필도 원래 상대 순서를 지켜 부모의 기존 프로필 뒤에 붙습니다. 어시스턴트와 MCP의 폴더 생성·이름 변경·이동·삭제는 검토 카드로 확인하며, 삭제 승인에는 열린 프로필 페이지가 필요하지 않습니다.

### 외형 라이브러리

그룹 페이지처럼 왼쪽 폴더 트리와 오른쪽 목록으로 구성됩니다. 폴더는 여러 단계로 만들 수 있고, 외형 설정은 폴더 안이나 최상위에 둘 수 있습니다.

예를 들어 `작품 A → 유나 → 기본 / 수영복`처럼 정리합니다. 여기서 작품과 캐릭터는 폴더이고, 기본·수영복은 서로 다른 외형 설정입니다. 한 캐릭터에 설정을 여러 개 만들 수 있습니다.

| 저장 항목 | 용도 |
| --- | --- |
| 외형 태그 | 정체성·머리·눈·얼굴·체형·피부·종족·기타 항목별 태그. 이미지 생성에 넣는 값은 항목과 기본 의상을 합친 태그입니다. |
| 의상 | 이름이 붙은 의상 태그 목록. 첫 번째가 기본 의상이며, 생성 화면에서 다른 의상을 고를 수 있습니다. |
| 즐겨찾기 | 목록에서 별로 표시하고 따로 모아 볼 수 있습니다. |
| 기준 이미지 | 아바타 자르기·자동 태그·자산 생성·워크플로우가 읽는 대표 이미지 한 장(★) |
| 참고 이미지 | 설정화·의상·포즈·소품 등 여러 장을 모아 두는 갤러리. 분류 이름은 직접 만들고, 생성 화면에 불러올 때 골라 넣을 수 있습니다. |
| 아바타 | 채팅 등에 표시할 이미지와 정사각형 자르기 위치·확대 |
| 표정 | 감정 키워드가 붙은 이미지 그룹 |
| 생성 후보 | 이 설정에서 만든 자산 배치의 이미지 후보 |

배경은 라이브러리 항목이 아니라 **채팅 프로필의 항목**입니다. 성격·인사말·모델·로어북도 프로필에서 따로 관리합니다.

## 외형 설정 만들기

1. `/characters`를 열고 **새 폴더**로 필요한 계층을 만듭니다.
2. 저장할 폴더에서 **새 외형 설정**을 누르고 이름과 폴더를 정한 뒤 **만들고 편집하기**를 누릅니다. 이때 빈 설정이 바로 만들어지고 목록 위의 상세 창에서 열립니다. 같은 위치의 이름은 대소문자를 구분하지 않고 중복을 막습니다.
3. 상세 창은 왼쪽에 기준 이미지와 아바타를, 오른쪽에 **태그 · 참고 이미지 · 표정 · 생성 후보** 탭을 둡니다. 이름은 창 제목에서 바로 고칩니다. 창 아래쪽 **‹ ›** 또는 키보드 **← →**(입력칸 밖에서)로 목록의 이전·다음 설정으로 넘어가며, 불러온 목록의 끝에서는 다음 묶음을 불러와 이어 갑니다. 창을 닫으면 목록의 보던 위치로 돌아갑니다. 좁은 화면에서는 창이 화면 전체를 쓰고 이미지 영역이 위로 올라갑니다.
4. **태그** 탭에서 항목별 태그를 칩으로 추가·삭제합니다. 입력칸에 쉼표로 여러 개를 한 번에 넣을 수 있고, 칩을 다른 항목 줄로 끌어 옮길 수 있습니다. 빈 항목은 **빈 항목** 줄에 모여 있으며 눌러서 엽니다. **의상**은 위의 의상 단추에서 고르고 추가·이름 변경·기본으로 지정·삭제합니다.
5. 왼쪽 기준 이미지 아래의 **올리기 · 가져오기(라이브러리·URL·파일 보관함) · 새로 생성 · 비우기**로 기준 이미지를 정합니다. 아바타는 **자르기**(기준 이미지에서 표시 영역 조정)와 **바꾸기**(다른 이미지·지우기)로 정합니다. 참고 이미지는 **참고 이미지** 탭에서 모읍니다.
6. 창 아래쪽의 **저장**(Ctrl+S)을 누릅니다. 즐겨찾기와 ⋯ 메뉴(폴더 이동·태그 복사·삭제)도 같은 줄에 있습니다. 저장하지 않고 다른 설정으로 넘어가거나 창을 닫으면 변경을 버릴지 먼저 확인하며, 이미 만든 빈 설정은 남습니다.

태그 탭 위쪽의 합친 태그 상자에서 **자동 채우기**로 항목을 채울 수 있습니다. 결과는 저장 전 초안에만 들어가며, 기존 항목을 덮어쓸 때는 먼저 확인합니다.

| 방법 | 채우는 내용 |
| --- | --- |
| Danbooru 캐릭터에서 | 고른 캐릭터와 작품 태그, 그 캐릭터 게시물에 자주 함께 쓰인 외형·의상 태그. 표정·구도 태그는 넣지 않습니다. |
| 기준 이미지 자동 태그에서 | 기준 이미지의 자동 태그(WD Tagger). 아직 태깅하지 않은 이미지는 이때 태깅합니다. |
| AI 초안 | 관리자 전용. 이름·기준 이미지·현재 태그를 보고 LLM이 쓴 태그 |
| 지금 태그 다시 분류 | 현재 태그를 항목에 다시 나눕니다. |

태그를 항목에 나누는 기준은 Danbooru 사전의 분류 트리입니다. **사전이 설치되어 있지 않으면 모든 태그가 기타 항목에 들어가고**, Danbooru·이미지 채우기와 필터를 쓸 수 없습니다. 사전은 프롬프트 화면의 Danbooru 탭에서 설치합니다. 복사 버튼은 합친 외형 태그를 클립보드에 넣고, 정체성에 Danbooru 캐릭터 태그가 있으면 Danbooru 링크가 나타납니다.

예전에 외형 설명 한 칸으로 저장한 설정은 그 글이 기타 항목에 들어간 것으로 읽습니다. **지금 태그 다시 분류**로 항목에 나눈 뒤 저장하세요.

### 목록에서 찾고 정리하기

- **검색**은 라이브러리 전체에서 설정 이름, 모든 의상을 포함한 태그, 태그의 한국어 이름을 찾습니다.
- **필터**(폴더 트리 아래)는 작품·캐릭터·인물·머리색·머리 길이·헤어스타일·눈색·피부색·종족·의상별로 태그와 해당 설정 수를 보여 줍니다. 같은 분류 안의 태그는 하나라도 맞으면, 서로 다른 분류는 모두 맞아야 표시합니다. 필터나 즐겨찾기를 켜면 폴더 구분 없이 전체에서 찾습니다.
- **정렬**은 이름순·최근 수정순·최근 추가순이며, **즐겨찾기**만 모아 볼 수 있습니다. 한 줄에 놓이는 카드 수는 목록 영역 너비(사이드바·채팅 독을 뺀 폭)에 맞춰 자동으로 정해지며, 캐릭터 카탈로그와 채팅 프로필 목록도 같습니다. 목록은 쪽 나눔 없이 아래로 스크롤하면 다음 묶음을 이어서 불러옵니다.
- 카드는 이미지 위에 이름, 작품(설치된 Danbooru 사전으로 태그에서 찾음), 의상 수(두 벌 이상일 때), 연결된 프로필 수, **참고 n · 표정 n**을 표시합니다. 이미지가 없으면 실루엣으로 표시합니다. 마우스를 올리면(터치 화면은 항상) 왼쪽 위 즐겨찾기, 오른쪽 위 선택·⋯ 메뉴가 나타나며, 태그 복사·편집은 ⋯ 메뉴와 우클릭에 있습니다. 마지막으로 연 카드와 선택한 카드는 카드 안쪽 테두리로 표시합니다. 카탈로그 카드에는 작품과 이미지 수가 나오며, **가져오기**(마지막으로 고른 폴더에 바로 만듦)·태그 복사·Danbooru 버튼이 있습니다. 채팅 프로필 카드는 모델·도구, 꺼짐·동기화 표시, 연결 상태(아바타의 빨간 점)와 **편집**·**복사** 버튼을, 그룹 첫 화면 카드는 그룹 색·이미지 수·자동수집 표시를 같은 형태로 보여 줍니다.
- 카드 메뉴에서 즐겨찾기, 태그 복사, 이동, 삭제를 합니다. 카드를 여러 개 고르면 아래 선택 막대에서 **즐겨찾기·이동·내보내기·삭제**를 한꺼번에 실행합니다. **불러온 항목 전부 선택**은 지금까지 스크롤해 불러온 설정을 모두 고릅니다. 이동할 폴더에 같은 이름이 하나라도 있으면 아무것도 옮기지 않습니다.
- 목록 메뉴의 **내보내기**는 현재 폴더(또는 선택한 설정)를 **외형 묶음 ZIP**으로 저장합니다. ZIP에는 설정 JSON(`character-library.json`)과 기준 이미지·아바타·참고 이미지(분류 포함)·표정(감정 키워드 포함)·생성 후보 이미지 파일이 함께 들어가므로 다른 CoNAI로 옮길 수 있습니다. `images.view`가 없으면 이미지는 빠집니다. 참고 이미지 기능이 없던 예전 CoNAI는 이 버전에서 내보낸 ZIP을 가져오지 못하지만, 예전 ZIP은 이 버전에서 그대로 가져올 수 있습니다.
- **외형 묶음 ZIP 가져오기**는 현재 폴더에 다시 만듭니다. 이름이 겹치면 `(2)`처럼 번호를 붙입니다. 묶음의 이미지는 라이브러리에 새로 넣고(이미 있는 이미지는 그대로 재사용), 표정과 후보 그룹도 다시 만듭니다. 이미지를 넣으려면 `images.view`와 `images.upload`가 필요하며, 권한이 없거나 읽을 수 없는 이미지는 빼고 가져온 뒤 개수를 알려 줍니다.

폴더의 작업 메뉴에서 하위 폴더·설정 추가, 이름 바꾸기, 이동, 삭제를 할 수 있습니다.

현재 폴더·검색·정렬·즐겨찾기·필터·열린 설정과 탭은 주소에 반영됩니다. 예를 들어 `/characters?setting=12`는 그 설정을 상세 창으로 엽니다.

### 캐릭터 카탈로그

`prompts.view` 권한이 있으면 첫 줄의 전환에 **캐릭터 카탈로그**가 나타납니다. Danbooru 사전의 캐릭터를 작품별로 둘러보는 읽기 전용 화면입니다. 왼쪽에서 작품을 고르고, 이름(영문 태그·한국어)으로 검색하며, 머리색·눈색 같은 외형 태그로 거르고, 많이 그려진 순 또는 이름순으로 정렬합니다. 목록은 아래로 스크롤하면 다음 묶음을 이어서 불러옵니다.

캐릭터를 누르면 상세 창이 열립니다. 왼쪽에는 사전의 샘플 이미지(작은 그림을 누르면 크게 보기), 오른쪽에는 게시물 수·Danbooru 링크와 가져올 외형 태그가 항목별(정체성·머리·눈…·기본 의상)로 나옵니다. 샘플 이미지가 없는 사전이면 오른쪽 내용만 보입니다.

- 태그를 누르면 가져올 목록에서 빠지고(취소선), 다시 누르면 들어갑니다. **태그 복사**는 남긴 태그만 복사합니다.
- `characters.edit`가 있으면 같은 창에서 **저장 위치**(폴더)와 **외형 설정 이름**을 정하고 **가져오기**를 누릅니다. 창은 그대로 남고 알림의 **열기**로 만든 설정을 열 수 있습니다. 바로 열려면 **가져와서 열기**를 누릅니다. 고른 폴더는 다른 캐릭터로 넘어가도 유지됩니다.
- `images.view`와 `images.upload`도 있으면 **샘플 이미지를 참고 이미지로 함께 가져오기**(기본 켬)가 나타납니다. 샘플 이미지는 새 설정의 미분류 참고 이미지로 들어가고 첫 장이 기준 이미지가 됩니다. 외형은 만들었지만 이미지를 넣지 못하면 그 사실을 따로 알려 줍니다.
- 아래쪽 **‹ ›** 또는 키보드 **← →**로 불러온 목록의 이전·다음 캐릭터로 넘어가며, 마지막 캐릭터에서는 다음 묶음을 불러와 이어 갑니다(입력칸에 커서가 있을 때는 제외). 이미 가져온 캐릭터에는 **가져옴** 표시와 **가져온 외형 열기**가 나옵니다.

카드의 **가져오기** 버튼은 창을 열지 않고 마지막으로 고른 폴더(처음에는 최상위, 버튼 설명에 폴더 이름 표시)에 바로 만들며, 가능하면 샘플 이미지도 함께 넣습니다. 이 화면에서 이미 가져온 캐릭터는 버튼이 **가져온 외형 열기**로 바뀝니다(페이지를 다시 열면 이 표시는 사라집니다). 가져오기 알림에는 들어간 폴더가 나오며, 샘플 이미지를 하나도 넣지 못했으면 오류 알림으로 보여 줍니다.

## 참고 이미지 갤러리

상세 창의 **참고 이미지** 탭에 참고 이미지를 여러 장 모아 둘 수 있습니다. 설정화, 의상, 포즈, 소품처럼 그 캐릭터를 그릴 때 볼 그림을 넣는 곳입니다.

- **추가** 메뉴(라이브러리에서 고르기·파일 올리기·URL·파일 보관함), 갤러리에 파일 끌어다 놓기, **Ctrl+V** 붙여넣기로 넣습니다. 파일 올리기·붙여넣기는 관리자 권한(`images.upload` 포함)이 필요합니다. 새 설정이면 이미지를 넣을 때 설정이 먼저 저장됩니다.
- 분류는 분류 줄의 **+**로 직접 만들고, 분류 단추의 메뉴에서 이름 변경·삭제를 합니다. 분류를 지우면 그 이미지는 지워지지 않고 **미분류**로 남습니다. 특정 분류를 고른 상태에서 넣은 이미지는 그 분류에 들어갑니다.
- 이미지의 ⋯ 메뉴(우클릭·길게 누르기도 같음)에 **기준으로**(★ 기준 이미지로 지정), **아바타로**(이 이미지에서 아바타 자르기), 분류 지정, 앞·뒤로 옮기기, **빼기**가 있습니다. 끌어서 순서를 바꿀 수도 있습니다. 기준 이미지와 아바타로 쓰는 이미지에는 **기준**·**아바타** 표시가 붙습니다.
- 갤러리 변경은 다른 태그 편집과 같이 **저장**해야 확정됩니다. 갤러리에서 빼도 이미지 라이브러리의 이미지는 지워지지 않습니다. 넣은 이미지는 그 설정의 이미지 그룹(`캐릭터 라이브러리/<이름> #<id>`)에 함께 보관됩니다.
- 미디어 라이브러리에서 갤러리 이미지를 지우면 삭제 확인에 그 이미지를 쓰는 외형 설정이 표시됩니다. 이미 지워진 이미지가 갤러리에 남아 있어도 다른 이미지의 추가·순서 변경은 막히지 않습니다.
- 갤러리는 보는 계정에 `images.view`가 있을 때만 보이고, 편집에는 `characters.edit`가 필요합니다. 분류 이름만 바꾸는 데는 `images.view`가 필요하지 않습니다.

## 기준 이미지·표정과 생성 후보

관리자는 기존 채팅 자산 생성과 같은 방식으로 기준 이미지·아바타·표정 후보를 만들고 골라 적용할 수 있습니다. 생성 배치와 후보 보관함은 **프로필이 아니라 외형 설정 소유**입니다. 연결된 여러 프로필에서 따로 같은 후보를 만들 필요가 없습니다.

- 후보 생성에는 관리자와 `characters.edit` 권한이 필요합니다. 생성 프리셋 등은 [채팅 가이드](CHAT.md)에서 확인합니다.
- 표정은 설정의 이미지 그룹에서 관리하며 채팅의 감정 키워드 이미지로 사용합니다.
- 이미지 보기·불러오기에는 `images.view`도 필요합니다. 라이브러리 보기 권한만으로 이미지 접근 권한이 생기지 않습니다.
- 후보 생성·적용이나 표정 편집은 저장된 설정에 반영될 수 있습니다. 편집 페이지를 떠나는 것을 이미 실행한 생성·적용의 취소로 생각하지 마세요.
- 외형 설정 창에서는 기준 이미지 아래 버튼(올리기·가져오기·새로 생성·비우기)과 아바타의 **자르기**·**바꾸기**로 고릅니다. 채팅 프로필 편집기에서는 **이미지 바꾸기** 메뉴 하나로 고릅니다(라이브러리에서 고르기·파일 올리기·URL·파일 보관함·새로 생성).
- **표정** 탭의 빈 칸에는 **올리기**(라이브러리·파일·URL·파일 보관함에서 그 감정 이미지 넣기)와 **생성**(생성할 수 있을 때만, 막힌 이유는 버튼 설명에 표시) 두 버튼이 따로 있습니다. 이미지 파일을 칸에 바로 끌어다 놓아도 됩니다. 한꺼번에 만들려면 위쪽 **빈 칸 N개 생성**을 누릅니다. 칸을 누르면 아래에 후보와 바꾸기·비우기가 나옵니다. 채팅 프로필 편집기의 표정 칸도 같습니다.

## 채팅 프로필에 연결하기

관리자는 **채팅 → 프로필** 또는 **설정 → 채팅 → 프로필**에서 연 프로필 편집 대화 상자의 **외형** 섹션에서 라이브러리를 연결합니다. 기본은 연결 없음이며, 필요할 때만 기존 **외형 설정 하나**를 연결합니다. 프로필과 외형 설정은 한 세트로 만들 필요가 없습니다.

| 상태 | 외형의 출처와 작업 |
| --- | --- |
| 연결 없음 | 기존처럼 프로필 자신의 외형을 씁니다. **라이브러리에서 불러오기**로 연결하거나 **라이브러리에 저장**으로 현재 외형을 새 설정으로 저장하고 동기화합니다. |
| 라이브러리와 동기화 중 | 연결할 때의 기본 상태입니다. 외형 설명·기준 이미지·아바타와 자르기·표정이 설정의 현재값을 따릅니다. 여기서 편집해 저장하면 라이브러리가 바뀌고, 같은 설정을 쓰는 모든 동기화 프로필에 반영됩니다. 화면에서 영향받는 프로필 수를 확인하세요. |
| 동기화 끊김 | **동기화 끊기** 후 저장하면 현재 외형의 사본을 프로필이 갖고 원본 설정을 기억합니다. 이후 프로필을 고쳐도 원본이나 다른 프로필은 바뀌지 않습니다. |

설정에 의상이 두 벌 이상이면 동기화 중인 외형 탭에 **이 프로필의 의상**이 나타납니다. 고른 의상은 프로필마다 따로 저장되므로, 같은 설정을 쓰는 프로필이 서로 다른 의상을 입을 수 있습니다(채팅의 이미지 생성도 그 의상을 씁니다). 의상은 이름으로 기억하므로 설정에서 그 의상 이름을 바꾸거나 지우면 기본(첫 번째) 의상으로 돌아가고, 화면에 **없는 의상** 안내가 나옵니다. 동기화를 끊으면 고른 의상을 입은 외형이 사본이 됩니다.

동기화가 끊긴 상태에서는 다음을 고를 수 있습니다.

- **원본에 덮어쓰기**: 현재 프로필의 외형으로 원본을 바꾸고 다시 동기화합니다. 확인창에 함께 바뀌는 동기화 프로필이 나옵니다.
- **원본으로 되돌리기**: 프로필의 독립 외형 대신 원본 설정을 다시 따릅니다. 프로필 저장으로 확정합니다.
- **새 설정으로 저장**: 별도의 설정으로 저장하고 그 설정과 동기화합니다.

**배경과 배경 생성은 동기화 중에도 프로필 소유**입니다. 기준 이미지·표정 생성은 동기화된 설정의 생성으로 바뀝니다.

분리하거나 연결을 해제한 **미저장 초안**에서는 아직 복사가 끝나지 않았으므로 원본 설정의 표정을 읽기 전용으로 보여 줍니다. 원본을 읽을 수 없으면 **표정은 연결된 라이브러리 설정 거야.**, 표정이 없으면 **그 설정엔 아직 표정이 없어.** 안내가 나옵니다. 저장하면 외형과 표정을 프로필로 복사하며, 원본을 기억하는 분리와 달리 연결 해제는 원본 연결도 없앱니다.

연결을 바꾼 뒤 **원본에 덮어쓰기**, **새 설정으로 저장**, 프로필 소유 생성·표정 변경을 실행하면 필요한 연결 변경을 먼저 저장합니다. 미저장 연결만 바꿔 둔 채 예전 소유자에 적용하지 않습니다. **라이브러리에서 열기**로 편집기를 떠날 때 미저장 변경이 있으면 확인하며, 프로필 자체 외형을 고친 뒤 다른 설정을 불러올 때도 먼저 확인합니다.

동기화 외형을 바꾼 뒤 프로필을 저장하면 설정을 먼저 저장합니다. 해결되지 않은 충돌이 있으면 프로필 저장까지 진행하지 않으므로, 안내에 따라 최신값과 초안을 확인하고 다시 저장합니다.

채팅의 프로필 변경 제안 카드로는 동기화 중인 외형을 저장할 수 없습니다. 제안으로 동기화 상태가 되는 경우도 같습니다. 외형만 바꾸는 제안은 이유를 알리고 거부하며, 다른 항목도 있으면 외형을 뺀 **나머지 저장**을 확인합니다. 외형은 라이브러리 설정에서 바꾸세요.

## 이미지 생성에 불러오기

생성 화면의 **캐릭터 불러오기**는 연결이 아니라 **그 시점의 값 복사**입니다. 나중에 라이브러리를 고쳐도 이미 채운 생성 폼은 바뀌지 않습니다. 외형 태그는 기존 프롬프트에 추가되고, 이미지는 사용할지 따로 고를 수 있습니다. 의상이 두 벌 이상이면 확인 단계에서 넣을 의상을 고릅니다(기본: 첫 번째 의상). 한 설정 안의 의상 이름은 서로 달라야 합니다(대소문자 무시).

이미지를 넣기로 하면 확인 단계에 설정의 **기준 이미지(★)와 참고 이미지**가 작은 그림으로 나오며 기준 이미지가 먼저 골라져 있습니다(기준 이미지가 없으면 첫 참고 이미지). NAI 캐릭터 레퍼런스는 여러 장을 고를 수 있습니다. 첫 장은 고른 칸(새 참조 또는 교체할 참조)에, 나머지는 새 참조 줄로 들어가며 순서는 갤러리 순서를 따릅니다. ComfyUI 이미지 필드에는 한 장만 넣습니다.

| 화면 | 불러오는 위치 |
| --- | --- |
| NAI | 메인 프롬프트와 각 캐릭터 프롬프트 줄. **캐릭터 불러와서 추가**는 새 캐릭터 프롬프트를 만듭니다. |
| Codex | 프롬프트. 기준 이미지는 참조 모드에서만 넣고, 넣으면 기존 마스크를 해제합니다. |
| ComfyUI | 폼의 버튼에서 태그를 넣을 marked text/textarea 필드와 선택적인 marked image 필드를 고릅니다. |

NAI의 설정 이미지는 캐릭터 레퍼런스를 지원하는 모델에서만 넣습니다. 기본은 **새 참조로 추가**이며 기존 참조가 있으면 **참조 k 교체 · 파일명**이나 **넣지 않기**를 고를 수 있습니다. 선택지가 하나면 이미지 포함 스위치를 끄면 됩니다. NAI의 여러 캐릭터 레퍼런스는 서로 섞여 사용되며, 특정 캐릭터 프롬프트와 일대일로 묶이지 않습니다.

ComfyUI 공개 워크플로우 페이지에서도 로그인한 계정에 `characters.view`가 있으면 사용할 수 있습니다. 참조 이미지 옵션은 `images.view`가 있을 때만 제공됩니다.

화면별 설명은 [NAI](NAI_GENERATION.md), [Codex](CODEX_GENERATION.md), [ComfyUI](COMFYUI_GENERATION.md)를 참고합니다.

## 워크플로우에서 사용하기

**생성 프리셋** 노드의 **캐릭터 외형 설정**에서 라이브러리 설정을 고를 수 있습니다. 채팅 프로필을 고르는 `profile_id`와 외형 설정 `character_setting_id`는 함께 지정할 수 없습니다.

**의상 이름**(`character_outfit`)에 설정의 의상 이름을 적거나 연결하면 그 의상을 입힙니다. 비우면 기본 의상입니다. 없는 이름이면 기본 의상으로 그리지 않고 실행을 멈추며, 있는 의상 목록을 알려 줍니다. 프로필을 고른 경우에는 프로필에 고른 의상을 쓰므로 의상 이름을 함께 넣을 수 없습니다.

실행할 때 설정의 외형 태그를 읽고, 실행 계정이 이미지를 볼 수 있으면 기준 이미지도 사용합니다. 연결된 `reference_image`가 있으면 그 이미지가 우선합니다. 이미지 권한이 없으면 설정에서는 태그만 사용합니다. 예약 실행도 지원하지만 **실행 입력 폼에는 설정 선택기가 없어 숫자 ID로 입력**합니다. 자세한 내용은 [워크플로우 편집](WORKFLOW_EDITOR.md)을 참고합니다.

## 저장 충돌과 삭제

- 설정 저장에는 읽었을 때의 `revision`이 사용됩니다. 다른 창이나 연결 프로필에서 먼저 바꾼 경우 서버는 `409 revision_conflict`로 오래된 덮어쓰기를 거부합니다. 편집기는 최신값을 읽어 겹치지 않는 변경을 합쳐 한 번 재시도하고, 같은 항목이 바뀌었으면 초안을 유지하며 확인을 요청합니다.
- 같은 위치의 이름이 겹치면 `409 name_conflict`입니다. 이름이나 폴더를 바꿔 다시 저장합니다.
- 삭제 전 미리보기로 범위를 확인합니다. 폴더 삭제는 하위 폴더와 설정도 지웁니다. 연결 프로필 이름은 관리자에게만 공개됩니다.
- 설정이나 폴더를 지워도 동기화 중인 프로필의 외형은 갑자기 비지 않습니다. **그때의 값을 프로필에 복사한 뒤 연결을 해제**합니다. 이미 동기화가 끊긴 프로필은 자신의 외형을 유지합니다.
- 직접 동기화 끊기·연결 해제 시 표정 사본의 그룹을 더해 프로필의 이모티콘 그룹 상한(10개)을 넘으면 저장을 거부하고 기존 연결 정리를 안내합니다. 설정 삭제는 이 상한 때문에 막지 않습니다.

## 어시스턴트와 MCP

현재 페이지 연결을 켜면 라이브러리의 폴더 이동·검색·필터·목록 더 불러오기·설정 열기·상세 창 탭 전환·새 초안·초안 채우기(항목·의상, 자동 채우기)와 참고 이미지 초안 편집(이미지 추가·분류 지정·빼기·기준 이미지 지정, 분류 추가·이름 변경·삭제)을 부탁할 수 있습니다. 즐겨찾기 표시는 바로 적용되고, 저장·삭제·폴더 만들기와 이름 변경·이동·여러 설정 이동과 삭제·카탈로그에서 가져오기는 검토 카드로 확정합니다. 예를 들어 “이 폴더에 수영복 외형 초안을 만들어 줘”라고 요청한 뒤 내용을 확인하고 저장합니다.

프로필 페이지 연결은 동기화 설정에 미저장 변경이 있으면 다른 설정으로 전환하는 초안을 거부합니다. 동기화 외형 설명을 채우려면 `characters.edit`가 필요하며, 생성 작업은 프로필 배경과 설정의 기준 이미지·표정을 구분합니다.

`profile.draft`로 다른 설정을 `synced: false` 상태로 지정하면 그 설정의 **저장된 외형**을 프로필 초안에 복사합니다. 현재 동기화 중인 설정에서 분리할 때는 저장값이 아니라 **현재 외형 초안**을 복사합니다. 프로필 저장 전까지는 독립 사본의 저장이 완료된 것이 아닙니다.

화면 없이 탐색하려면 `list_character_library`(필터·정렬·필터 후보), `get_character_setting`, 저장 없이 외형 초안을 만들려면 `fill_character_appearance`, 폴더 정리는 `manage_character_folders`를 사용합니다. `get_character_setting`은 참고 이미지(`references`)와 분류(`referenceCategories`)도 돌려주며, `propose_character_library`의 저장 제안은 두 목록을 통째로 바꿀 수 있습니다. 검토 카드에는 남는 참고 이미지 수와 분류별 개수, 분류 목록이 표시됩니다. `propose_character_library`는 채팅에서만 변경 검토 카드를 만듭니다. 제안 자체는 저장이나 생성을 실행하지 않습니다. 생성 화면의 `character_setting.insert`는 `referenceHashes`로 넣을 설정 이미지를 순서대로 고를 수 있습니다(NAI 캐릭터 레퍼런스는 여러 장, 그 밖의 입력은 한 장). 인자와 권한은 [MCP 가이드](MCP_GUIDE.md)를 참고합니다.
