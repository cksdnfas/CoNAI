# 캐릭터 라이브러리

캐릭터의 외형을 한 번 등록해 채팅 프로필과 이미지 생성에서 다시 쓰는 기능입니다. 대화 성격·모델을 가진 채팅 프로필과 달리, 라이브러리의 **외형 설정**은 이미지 프롬프트용 태그와 그림을 보관합니다.

## 관련 페이지

| 목적 | 경로 |
| --- | --- |
| 캐릭터 라이브러리 | `/characters` |
| 채팅 프로필 연결 | `/characters?view=profiles` → 프로필 편집 → 외형 |
| 이미지 생성에 불러오기 | `/generation` → NAI / Codex / ComfyUI |
| 워크플로우에서 사용 | `/generation?tab=workflows` → 생성 프리셋 노드 |

상단의 **캐릭터**(기본 고정 페이지, 휴대폰은 하단 탭)로 이동합니다. 고정을 풀었다면 **라이브러리** 메뉴에 있습니다. 어디에도 없으면 `characters.view` 권한을 확인합니다.

관리자는 첫 줄 맨 앞의 **외형 라이브러리 · 채팅 프로필** 전환으로 두 화면을 오갑니다. 채팅 프로필 목록은 설정에서 이곳으로 옮겼고, 프로필을 누르면 편집 페이지(`/characters?view=profiles&profile=<id>`)가 열립니다. `/characters?setting=12`처럼 특정 외형 설정을 여는 주소는 그대로 동작합니다. 페르소나·플래그는 **설정 → 내 설정**, 프리셋·표시 블록·로어북은 **채팅 → 채팅 자원**에서 관리합니다.

## 폴더와 외형 설정

### 채팅 프로필 탭

관리자의 **채팅 프로필** 탭도 같은 폴더 사이드바·경로·검색·3:4 카드 목록을 사용합니다. 프로필 폴더와 외형 폴더는 별개입니다. **새 폴더**로 만들고 폴더 메뉴에서 이름 변경·이동·삭제를 할 수 있습니다. **프로필 폴더를 삭제해도 프로필은 지워지지 않습니다.** 안의 프로필과 하위 폴더는 삭제한 폴더의 부모로 옮겨집니다. 부모에 같은 이름의 폴더가 있으면 삭제가 취소되므로 먼저 이름을 바꾸세요.

카드는 연결된 외형의 기준 이미지, 연결이 없으면 프로필 아바타를 표시합니다. 꺼진 프로필은 흐리게 표시되며 모델·도구와 연결 문제도 확인할 수 있습니다. 우클릭·길게 누르기 또는 카드의 작업 버튼으로 편집·복사·폴더 이동·켜기/끄기를 실행합니다. 같은 폴더의 카드를 끌어 순서를 바꾸면 채팅 선택기에도 반영됩니다. 검색 중에는 순서 변경 대신 폴더를 먼저 여세요.

**새 프로필**, 복사, 캐릭터 카드 가져오기는 현재 폴더에 초안을 만들며 편집기의 **프로필 폴더**에서 바꿀 수 있습니다. 검색 중 새 항목과 새 폴더는 최상위에 만듭니다. 빈 새 프로필은 폴더만 지정되어 있어도 미저장 변경으로 표시하지 않습니다. 검색은 모든 프로필 이름을 찾습니다. 주소의 `view=profiles`, `folder`, `q`, `page`, `profile`이 탐색 위치와 열린 편집기를 보존합니다. 다른 폴더로 옮긴 프로필은 그 폴더의 맨 뒤에 붙습니다. 폴더를 지워 부모로 올라온 프로필도 원래 상대 순서를 지켜 부모의 기존 프로필 뒤에 붙습니다. 어시스턴트와 MCP의 폴더 생성·이름 변경·이동·삭제는 검토 카드로 확인하며, 삭제 승인에는 열린 캐릭터 페이지가 필요하지 않습니다.

### 외형 라이브러리

그룹 페이지처럼 왼쪽 폴더 트리와 오른쪽 목록으로 구성됩니다. 폴더는 여러 단계로 만들 수 있고, 외형 설정은 폴더 안이나 최상위에 둘 수 있습니다.

예를 들어 `작품 A → 유나 → 기본 / 수영복`처럼 정리합니다. 여기서 작품과 캐릭터는 폴더이고, 기본·수영복은 서로 다른 외형 설정입니다. 한 캐릭터에 설정을 여러 개 만들 수 있습니다.

| 저장 항목 | 용도 |
| --- | --- |
| 외형 설명 | 머리·눈·의상 등 이미지 생성에 넣을 외형 태그 |
| 기준 이미지 | 외형을 참고할 이미지 한 장 |
| 아바타 | 채팅 등에 표시할 이미지와 정사각형 자르기 위치·확대 |
| 표정 | 감정 키워드가 붙은 이미지 그룹 |
| 생성 후보 | 이 설정에서 만든 자산 배치의 이미지 후보 |

배경은 라이브러리 항목이 아니라 **채팅 프로필의 항목**입니다. 성격·인사말·모델·로어북도 프로필에서 따로 관리합니다.

## 외형 설정 만들기

1. `/characters`를 열고 **새 폴더**로 필요한 계층을 만듭니다.
2. 저장할 폴더에서 **새 외형 설정**을 누르고 이름과 폴더를 정한 뒤 **만들고 편집하기**를 누릅니다. 이때 빈 설정이 바로 만들어지고 편집 페이지가 열립니다. 같은 위치의 이름은 대소문자를 구분하지 않고 중복을 막습니다.
3. 위쪽 경로 줄(캐릭터 라이브러리 › 폴더)로 목록에 돌아갈 수 있습니다.
4. **외형 설명**에 이미지 프롬프트용 태그를 적고, 필요하면 기준 이미지와 아바타를 고릅니다.
5. 아바타의 **기준 이미지에서 자르기**로 표시 영역을 조정할 수 있습니다.
6. 아래 저장 줄의 **저장**(Ctrl+S)을 누릅니다. 저장하지 않고 페이지를 떠나면 변경을 버릴지 먼저 확인하며, 이미 만든 빈 설정은 남습니다.

관리자는 외형 설명 오른쪽의 **AI 초안**으로 기준 이미지나 프롬프트를 보고 외형 설명의 초안을 만들 수 있습니다. 결과를 확인한 뒤 저장하세요.

폴더의 작업 메뉴에서 하위 폴더·설정 추가, 이름 바꾸기, 이동, 삭제를 할 수 있습니다. 외형 설정도 다른 폴더로 옮길 수 있습니다. 검색은 현재 폴더 안이 아니라 **라이브러리 전체의 설정 이름**을 찾으며, 목록은 페이지로 나뉩니다.

현재 폴더·검색·페이지·편집 중인 설정은 주소의 `folder`, `q`, `page`, `setting`, `new`에 반영됩니다. 예를 들어 `/characters?setting=12`는 그 설정을 엽니다.

## 기준 이미지·표정과 생성 후보

관리자는 기존 채팅 자산 생성과 같은 방식으로 기준 이미지·아바타·표정 후보를 만들고 골라 적용할 수 있습니다. 생성 배치와 후보 보관함은 **프로필이 아니라 외형 설정 소유**입니다. 연결된 여러 프로필에서 따로 같은 후보를 만들 필요가 없습니다.

- 후보 생성에는 관리자와 `characters.edit` 권한이 필요합니다. 생성 프리셋 등은 [채팅 가이드](CHAT.md)에서 확인합니다.
- 표정은 설정의 이미지 그룹에서 관리하며 채팅의 감정 키워드 이미지로 사용합니다.
- 이미지 보기·불러오기에는 `images.view`도 필요합니다. 라이브러리 보기 권한만으로 이미지 접근 권한이 생기지 않습니다.
- 후보 생성·적용이나 표정 편집은 저장된 설정에 반영될 수 있습니다. 편집 페이지를 떠나는 것을 이미 실행한 생성·적용의 취소로 생각하지 마세요.
- 기준 이미지·아바타는 **이미지 바꾸기** 메뉴 하나로 고릅니다(라이브러리에서 고르기·파일 올리기·URL·파일 보관함·새로 생성). 표정 빈 칸은 **+ 만들기**, 한꺼번에 만들려면 **빈 칸 N개 만들기**를 누릅니다.

## 채팅 프로필에 연결하기

관리자는 프로필 편집 페이지의 **외형** 섹션에서 라이브러리를 연결합니다. 한 프로필은 **외형 설정 하나**에 연결됩니다.

| 상태 | 외형의 출처와 작업 |
| --- | --- |
| 연결 없음 | 기존처럼 프로필 자신의 외형을 씁니다. **라이브러리에서 불러오기**로 연결하거나 **라이브러리에 저장**으로 현재 외형을 새 설정으로 저장하고 동기화합니다. |
| 라이브러리와 동기화 중 | 연결할 때의 기본 상태입니다. 외형 설명·기준 이미지·아바타와 자르기·표정이 설정의 현재값을 따릅니다. 여기서 편집해 저장하면 라이브러리가 바뀌고, 같은 설정을 쓰는 모든 동기화 프로필에 반영됩니다. 화면에서 영향받는 프로필 수를 확인하세요. |
| 동기화 끊김 | **동기화 끊기** 후 저장하면 현재 외형의 사본을 프로필이 갖고 원본 설정을 기억합니다. 이후 프로필을 고쳐도 원본이나 다른 프로필은 바뀌지 않습니다. |

동기화가 끊긴 상태에서는 다음을 고를 수 있습니다.

- **원본에 덮어쓰기**: 현재 프로필의 외형으로 원본을 바꾸고 다시 동기화합니다. 확인창에 함께 바뀌는 동기화 프로필이 나옵니다.
- **원본으로 되돌리기**: 프로필의 독립 외형 대신 원본 설정을 다시 따릅니다. 프로필 저장으로 확정합니다.
- **새 설정으로 저장**: 별도의 설정으로 저장하고 그 설정과 동기화합니다.

**배경과 배경 생성은 동기화 중에도 프로필 소유**입니다. 기준 이미지·표정 생성은 동기화된 설정의 생성으로 바뀝니다.

분리하거나 연결을 해제한 **미저장 초안**에서는 아직 복사가 끝나지 않았으므로 원본 설정의 표정을 읽기 전용으로 보여 줍니다. 원본을 읽을 수 없으면 **표정은 연결된 라이브러리 설정 거야.**, 표정이 없으면 **그 설정엔 아직 표정이 없어.** 안내가 나옵니다. 저장하면 외형과 표정을 프로필로 복사하며, 원본을 기억하는 분리와 달리 연결 해제는 원본 연결도 없앱니다.

연결을 바꾼 뒤 **원본에 덮어쓰기**, **새 설정으로 저장**, 프로필 소유 생성·표정 변경을 실행하면 필요한 연결 변경을 먼저 저장합니다. 미저장 연결만 바꿔 둔 채 예전 소유자에 적용하지 않습니다. **라이브러리에서 열기**로 편집기를 떠날 때 미저장 변경이 있으면 확인하며, 프로필 자체 외형을 고친 뒤 다른 설정을 불러올 때도 먼저 확인합니다.

동기화 외형을 바꾼 뒤 프로필을 저장하면 설정을 먼저 저장합니다. 해결되지 않은 충돌이 있으면 프로필 저장까지 진행하지 않으므로, 안내에 따라 최신값과 초안을 확인하고 다시 저장합니다.

채팅의 프로필 변경 제안 카드로는 동기화 중인 외형을 저장할 수 없습니다. 제안으로 동기화 상태가 되는 경우도 같습니다. 외형만 바꾸는 제안은 이유를 알리고 거부하며, 다른 항목도 있으면 외형을 뺀 **나머지 저장**을 확인합니다. 외형은 라이브러리 설정에서 바꾸세요.

## 이미지 생성에 불러오기

생성 화면의 **캐릭터 불러오기**는 연결이 아니라 **그 시점의 값 복사**입니다. 나중에 라이브러리를 고쳐도 이미 채운 생성 폼은 바뀌지 않습니다. 외형 태그는 기존 프롬프트에 추가되고, 기준 이미지는 사용할지 따로 고를 수 있습니다.

| 화면 | 불러오는 위치 |
| --- | --- |
| NAI | 메인 프롬프트와 각 캐릭터 프롬프트 줄. **캐릭터 불러와서 추가**는 새 캐릭터 프롬프트를 만듭니다. |
| Codex | 프롬프트. 기준 이미지는 참조 모드에서만 넣고, 넣으면 기존 마스크를 해제합니다. |
| ComfyUI | 폼의 버튼에서 태그를 넣을 marked text/textarea 필드와 선택적인 marked image 필드를 고릅니다. |

NAI의 기준 이미지는 캐릭터 레퍼런스를 지원하는 모델에서만 넣습니다. 기본은 **새 참조로 추가**이며 기존 참조가 있으면 **참조 k 교체 · 파일명**이나 **넣지 않기**를 고를 수 있습니다. 선택지가 하나면 이미지 포함 스위치를 끄면 됩니다. NAI의 여러 캐릭터 레퍼런스는 서로 섞여 사용되며, 특정 캐릭터 프롬프트와 일대일로 묶이지 않습니다.

ComfyUI 공개 워크플로우 페이지에서도 로그인한 계정에 `characters.view`가 있으면 사용할 수 있습니다. 참조 이미지 옵션은 `images.view`가 있을 때만 제공됩니다.

화면별 설명은 [NAI](NAI_GENERATION.md), [Codex](CODEX_GENERATION.md), [ComfyUI](COMFYUI_GENERATION.md)를 참고합니다.

## 워크플로우에서 사용하기

**생성 프리셋** 노드의 **캐릭터 외형 설정**에서 라이브러리 설정을 고를 수 있습니다. 채팅 프로필을 고르는 `profile_id`와 외형 설정 `character_setting_id`는 함께 지정할 수 없습니다.

실행할 때 설정의 외형 태그를 읽고, 실행 계정이 이미지를 볼 수 있으면 기준 이미지도 사용합니다. 연결된 `reference_image`가 있으면 그 이미지가 우선합니다. 이미지 권한이 없으면 설정에서는 태그만 사용합니다. 예약 실행도 지원하지만 **실행 입력 폼에는 설정 선택기가 없어 숫자 ID로 입력**합니다. 자세한 내용은 [워크플로우 편집](WORKFLOW_EDITOR.md)을 참고합니다.

## 저장 충돌과 삭제

- 설정 저장에는 읽었을 때의 `revision`이 사용됩니다. 다른 창이나 연결 프로필에서 먼저 바꾼 경우 서버는 `409 revision_conflict`로 오래된 덮어쓰기를 거부합니다. 편집기는 최신값을 읽어 겹치지 않는 변경을 합쳐 한 번 재시도하고, 같은 항목이 바뀌었으면 초안을 유지하며 확인을 요청합니다.
- 같은 위치의 이름이 겹치면 `409 name_conflict`입니다. 이름이나 폴더를 바꿔 다시 저장합니다.
- 삭제 전 미리보기로 범위를 확인합니다. 폴더 삭제는 하위 폴더와 설정도 지웁니다. 연결 프로필 이름은 관리자에게만 공개됩니다.
- 설정이나 폴더를 지워도 동기화 중인 프로필의 외형은 갑자기 비지 않습니다. **그때의 값을 프로필에 복사한 뒤 연결을 해제**합니다. 이미 동기화가 끊긴 프로필은 자신의 외형을 유지합니다.
- 직접 동기화 끊기·연결 해제 시 표정 사본의 그룹을 더해 프로필의 이모티콘 그룹 상한(10개)을 넘으면 저장을 거부하고 기존 연결 정리를 안내합니다. 설정 삭제는 이 상한 때문에 막지 않습니다.

## 어시스턴트와 MCP

현재 페이지 연결을 켜면 라이브러리의 폴더 이동·검색·설정 열기·새 초안·초안 채우기를 부탁할 수 있습니다. 저장과 삭제는 검토 카드로 확정합니다. 예를 들어 “이 폴더에 수영복 외형 초안을 만들어 줘”라고 요청한 뒤 내용을 확인하고 저장합니다.

프로필 페이지 연결은 동기화 설정에 미저장 변경이 있으면 다른 설정으로 전환하는 초안을 거부합니다. 동기화 외형 설명을 채우려면 `characters.edit`가 필요하며, 생성 작업은 프로필 배경과 설정의 기준 이미지·표정을 구분합니다.

`profile.draft`로 다른 설정을 `synced: false` 상태로 지정하면 그 설정의 **저장된 외형**을 프로필 초안에 복사합니다. 현재 동기화 중인 설정에서 분리할 때는 저장값이 아니라 **현재 외형 초안**을 복사합니다. 프로필 저장 전까지는 독립 사본의 저장이 완료된 것이 아닙니다.

화면 없이 탐색하려면 `list_character_library`, `get_character_setting`, 폴더 정리는 `manage_character_folders`를 사용합니다. `propose_character_library`는 채팅에서만 변경 검토 카드를 만듭니다. 제안 자체는 저장이나 생성을 실행하지 않습니다. 인자와 권한은 [MCP 가이드](MCP_GUIDE.md)를 참고합니다.
