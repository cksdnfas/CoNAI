# 스프라이트

**만들기 → 스프라이트**에서 라이브러리 이미지·영상을 고르고 처리합니다. 원본은 변경하지 않습니다.
추출·정규화·애니메이션은 같은 작업 큐에서 실행하며 진행률과 취소 버튼을 제공합니다.
라이브러리 저장에는 이미지 편집·업로드 권한이 필요합니다.

## 원본 정규화

**원본 정규화** 탭은 모션 생성에 넣을 **불투명 배경 PNG**를 만듭니다. 추출의 디스필·투명화와 다른 작업입니다.

1. 이미지 또는 **영상 마지막 프레임**을 고르고 라이브러리에서 원본들을 선택합니다.
2. 배경 지정색을 고릅니다. 기본은 마젠타 `#FF00FF`이며 모든 `#RRGGBB`를 사용할 수 있습니다.
3. 이미지는 작업 크기(기본 1024), 캔버스 크기(1600), 하단/중앙 기준점과 하단 여백을 지정합니다.
4. 작업 크기·캔버스·둘 다 중 보관할 출력을 선택하고 저장 그룹 경로를 입력합니다. 비우면 `스프라이트` 그룹입니다.
5. 라이브러리 저장 또는 ZIP 다운로드를 실행합니다. 저장 후에도 결과 ZIP을 받을 수 있습니다.

알파를 정확한 지정색 위에 합성하고, RGB 거리가 허용치(기본 40) 이내인 픽셀을 정확한 색으로 맞춥니다.
바깥쪽 2px 링은 지정색 계열도 맞춥니다. 색상각을 마젠타 위치로 회전시킨 HSV 공간에서 원래의
`R≥160, B≥160, G≤100` 영역을 검사하므로 마젠타 동작은 동일합니다. 회색·흰색·검정은 색상각이 없으므로 거리 검사만 합니다.
직사각형은 긴 변의 정사각형에 가로 중앙·하단 기준으로 패딩하며 늘려 찌그러뜨리지 않습니다.
LANCZOS로 작업 크기를 만들고 다시 색을 맞춘 뒤 캔버스에 배치하고 다시 검사합니다. 중앙 기준점은 하단 여백을 무시합니다.

영상은 마지막 프레임을 정사각 패딩 후 곧바로 캔버스 크기로 맞춥니다. `0 < 배율 ≤ 1`로 균일하게 중앙 축소할 수 있고
X/Y 이동을 적용할 수 있습니다. 이동으로 캐릭터·소품 등 지정색이 아닌 픽셀이 잘리면 거절합니다.
영상 출력은 캔버스 한 장이며 이미지용 작업 크기·하단 여백·출력 선택은 사용하지 않습니다.
마지막 프레임 입력은 라이브러리 선택기와 MCP 모두 `video/*` 영상으로 제한합니다. 애니메이션 GIF/WebP는 지원하지 않습니다.

각 출력에 **테두리가 정확한 지정색인지**, **남은 근사색 픽셀 수**, **OK/FAIL**을 표시합니다.
남은 근사색은 스냅 허용치와 무관하게 지정색과 RGB 거리가 **40 이내**이면서 정확한 지정색이 아닌 픽셀을 셉니다.
FAIL도 검토할 수 있도록 저장하지만 모션 생성에 쓰기 전에 확인해야 합니다. 다른 테이크를 쓰거나 배치·허용치를 조정하세요.
파일별 처리 오류는 다른 원본의 처리를 막지 않습니다. 한 번에 최대 500개를 순차 처리하며 기존 픽셀·메모리 한도를 적용합니다.

## 시트 정규화

**정규화** 탭에서 추출한 시트의 열·행·프레임 수·입력 간격·읽는 순서를 확인합니다.
기존 **시트별 / 묶음 공통**은 원본 픽셀과 기준점을 보존하며 여백만 맞춥니다. 기본 동작은 변경되지 않았습니다.

**고정 납품 셀**은 모든 프레임을 지정한 너비×높이에 담습니다.

- **몸 높이**에 맞춰 가로·세로를 같은 비율로 조정합니다.
- **딛는 발**: 가장 낮은 불투명 픽셀에서 `발 밴드` 범위의 X 중심을 찾습니다. 발 알파 임계값(기본 200)은 얇은 프린지가 발 위치를 끌어가지 않게 합니다. 몸 박스 하단은 셀 하단 여백 위에 놓입니다.
- **첫 프레임 중앙**: 첫 프레임 박스 중심을 셀 중앙에 놓고 이후 프레임의 상대 이동·반동을 유지합니다. 하단 여백은 사용하지 않습니다.
- 기준 높이를 비우면 첫 프레임 박스 높이가 기준입니다. 끝 기준 높이를 넣으면 선형 보간하고, 곡선에는 균등 간격 시점의 높이를 쉼표로 입력합니다. 곡선이 두 점 이상일 때만 선형 설정보다 우선하며, 한 점이면 기준 높이·끝 기준 높이의 선형 보간을 사용합니다.
- **프레임마다 몸 높이 맞추기**는 기준 높이·곡선 대신 각 프레임의 실제 박스 높이를 사용합니다.

셀을 넘는 프레임은 자르지 않고 오류로 알려 줍니다. 셀을 키우거나 몸 높이를 줄이세요.
빈 프레임은 납품 모드에서 오류입니다. 알파 임계값으로 몸 박스를 측정하고 premultiplied alpha LANCZOS로 리샘플링해 투명 가장자리의 색 번짐을 방지합니다.

## 어시스턴트와 MCP

페이지 어시스턴트는 열린 탭의 원본 선택·옵션 입력·실행·결과 검사에 연결됩니다.
라이브러리 저장은 검토 카드로, 저장 없는 ZIP 다운로드는 즉시 실행합니다.
원본 탭의 `sprite.add_sources`/`sprite.remove_sources`, `sprite.run`/`sprite.download`/`sprite.stop`은 안정된 작업 ID입니다.
납품 옵션 필드는 `delivery.frameWidth`, `delivery.bodyHeight`, `delivery.pivot` 등입니다.

화면 없이 실행할 때는 [MCP 가이드](./MCP_GUIDE.md)의 `normalize_sprite_sources`, `normalize_sprite_sheets`를 사용합니다.
긴 작업은 `get_sprite_job`으로 상태·해시·검사 결과·다운로드를 확인합니다.
추출·디스필·애니메이션의 기존 도구와 옵션은 그대로 사용할 수 있습니다.
