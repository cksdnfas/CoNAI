# 파일 보관함

상단 **파일 보관함**에서 내 파일을 업로드하고 폴더별로 정리합니다. 파일은 계정별로 분리되며 채팅에 첨부한 원본은 참조가 남아 있는 동안 삭제되지 않습니다.

파일을 누르면 미리보기가 열립니다. 위쪽 화살표 또는 키보드 **← →**로 같은 폴더의 파일을 이름순으로 넘깁니다. 목록의 100개 페이지 경계를 넘어도 이어집니다. 다운로드 아이콘은 원본을 저장합니다.

| 형식 | 미리보기 |
| --- | --- |
| 이미지 | 원본 비율로 표시 |
| 동영상·음성 | 재생·탐색 컨트롤, byte Range 지원 |
| PDF | 페이지별 보기와 이전·다음 페이지 |
| UTF-8 텍스트·코드 | 줄 번호, 자동 줄바꿈, 다음 부분 읽기. JS·TS·Python·JSON·YAML·SQL·CSS·XML·셸 코드 강조 |
| Markdown | 채팅과 같은 Markdown 표시, 원문 전환 |
| JSON | 한 부분에 들어오는 문서는 들여쓰기 정렬, 원문 전환 |
| CSV·TSV | 앞부분 최대 200행·50열을 표로 표시. 따옴표 안 쉼표·줄바꿈 지원, 원문 전환 |
| HTML·SVG | 실행하지 않고 소스 텍스트로 표시 |

## 검색

툴바의 돋보기를 누르면 경로 자리에 검색창이 열립니다. 내 보관함 전체에서 이름이나 내용에 검색어가 들어간 파일·폴더를 찾고, 결과는 파일명·폴더 경로·찾은 문장 일부로 표시됩니다. 결과를 누르면 미리보기가 열리고, **Esc**나 ✕로 검색을 닫습니다.

- 띄어 쓴 단어는 모두 들어 있어야 찾습니다. `"캐릭터 설정"`처럼 따옴표로 묶으면 그 문장 그대로 찾습니다.
- 영문은 대소문자를 구분하지 않습니다. 한 글자·두 글자 검색어도 됩니다.
- 내용 검색 대상은 UTF-8 텍스트 형식(Markdown, txt, JSON, CSV 등)입니다. HTML은 태그·스크립트·스타일을 뺀 보이는 글자만 찾습니다. PDF·Office 문서는 이름만 찾습니다.
- 파일 앞부분 2MB까지만 내용을 찾습니다. 결과는 최대 50개이며 이름이 맞은 항목이 먼저 나옵니다.
- 채팅은 `search_files` 도구로 같은 검색을 하고, 보관함 페이지를 연결했을 때는 검색어를 채워 검색 화면을 엽니다.

내용은 검색할 때 바뀐 파일만 다시 읽어 `search.db`에 저장해 둡니다(크기·수정 시각 기준). 그래서 처음 검색할 때는 파일이 많으면 조금 걸립니다. 삭제한 파일의 내용은 삭제와 함께 지워집니다. `search.db`는 원본에서 다시 만들 수 있는 사본이라 DB 백업에 들어가지 않고, 지우거나 깨져도 다음 검색 때 다시 만들어집니다.

큰 텍스트는 한 번에 약 16KB씩 읽습니다. 한글 UTF-8 문자가 중간에 잘리지 않으며 **처음**으로 돌아갈 수 있습니다. 지원되지 않는 형식·코덱·암호화 PDF는 원본을 다운로드해서 엽니다.

아이콘 보기에서 이미지와 동영상은 썸네일이 나옵니다. 동영상은 1초 지점(짧은 영상은 첫 프레임)을 사용하고 `.thumbs`에 캐시합니다. 파일 삭제 때 캐시도 정리됩니다. FFmpeg가 없거나 디코딩이 실패하면 형식 아이콘을 표시합니다.

## 구현·검증 기록 (2026-10-04)

보기 경로 `GET /api/files/:id/view`는 파일 소유권을 확인하고, 업로드 MIME 대신 파일 헤더로 허용 형식을 판별합니다. HTML·SVG와 텍스트 확장자는 `text/plain; charset=utf-8`로 강제합니다. `nosniff`와 `Content-Security-Policy: sandbox`를 적용하고, 기존 다운로드는 `application/octet-stream` + attachment를 유지합니다.

PDF는 [PDF.js의 페이지 렌더링](https://mozilla.github.io/pdf.js/examples/)으로 만든 이미지를 스크립트 없는 sandbox iframe에 표시합니다. 문서 스크립트·폼·링크는 실행하지 않습니다. 폰트·CMap·워커는 앱에서 제공하며 외부 CDN에 파일을 보내지 않습니다. 프로젝트의 Node 20.19 호환 범위를 유지하도록 PDF.js는 5.6.205로 고정합니다. PDF 뷰어는 필요할 때만 로드됩니다(현재 JS 약 542KB, gzip 172KB, 별도 워커 약 1.2MB). 코드 강조도 [필요한 언어만 등록한 highlight.js](https://highlightjs.org/#usage)를 지연 로딩합니다(약 64KB, gzip 22KB).

격리 백엔드와 Vite preview에서 이미지·동영상·음성·PDF·텍스트·TS·MD·JSON·CSV·HTML·SVG 표시를 확인했습니다. HTML 실행 차단, 다른 계정 파일의 보기·텍스트·썸네일·이웃 조회 404, Range 206/416, 동시 썸네일 요청, 큰 한글 텍스트 분할 읽기와 원본 다운로드를 확인했습니다.
