# 설정 전체 지도

설정 페이지는 **내 설정(나에게만)**과 **앱 관리(공용 · 관리자)**로 나뉩니다. 페르소나·플래그는 내 설정에서, 공용 테마·동작·연결·보안은 앱 관리에서 바꿉니다.

## 관련 페이지

| 목적 | 경로 |
| --- | --- |
| 설정 | `/settings` |
| 접근 가능 페이지 확인 | `/access` |
| 로그인 | `/login` |
| 감시폴더 그룹 | `/groups?tab=folders` |

앱 관리는 관리자이거나 아직 인증 정보가 없는 초기 상태에서 열 수 있습니다. 내 설정(`/settings?section=mine`)은 채팅 페이지 권한이 있는 계정도 사용할 수 있습니다. 현재 기본 언어·테마·화면 밀도는 공용 저장값이므로 내 설정으로 옮기지 않습니다. 계정 메뉴의 언어 선택은 브라우저별 선택입니다.

## 작업 중인 페이지에서 설정하기

앱 상단 오른쪽의 **게시판 설정**, **생성 설정** 같은 글자 버튼(슬라이더 아이콘)을 누르면 오른쪽 설정 시트가 열립니다. 폭이 1024px보다 좁으면 슬라이더 아이콘 버튼과 전체 높이 시트를 사용합니다. 앱 전체 설정은 계정 메뉴의 **설정**(톱니)과 **내 설정**에서 엽니다. 관리자의 허용된 항목만 보이며, 서버의 기존 페이지 설정 API와 위임 권한 계약은 유지됩니다.

| 페이지 | 연결되는 설정 |
| --- | --- |
| 홈·그룹 | 라이브러리 표시, 유사도, 썸네일, 의미 검색 |
| 이미지 상세·메타데이터 편집 | 유사도, 메타데이터 추출, 이미지 저장, 태거·작가 분석 |
| 업로드 | 이미지·영상 저장, 메타데이터 추출, 태거·작가 분석 |
| 생성·워크플로 | 생성 동시 실행과 간격, 이미지·영상 저장 |
| 게시판 | 목록 기본값, 봇 호출 제한, 지식 평가·주제 자동 평가, 의미 검색 |
| 채팅 | 공용 채팅 활성화, 로어북 자동 저장, 답변 진단, 의미 검색 |
| 프롬프트·파일·스프라이트 | 각각 유사도·의미 검색·이미지 저장 |

각 페이지에서 공용 테마·화면 밀도도 조정할 수 있습니다. 오디오·월페이퍼·와일드카드의 상단 버튼은 **공용 화면 설정**이며, 오디오의 기존 워크플로·내보내기·단축키 모달과 월페이퍼 편집 기능은 해당 화면에서 계속 사용합니다. 로그인·접근 안내·공개 워크플로·월페이퍼 실행 화면에는 공용 설정 버튼을 표시하지 않습니다.

시트의 공용 설정은 **모든 사용자에게 적용**됩니다. 업로드의 이번 작업 옵션이나 채팅의 개인 설정과 구분하세요. 시트는 소제목으로 묶인 항목 중 선택한 항목만 조회하고 변경한 값만 저장합니다. 닫기·항목 전환 때 미저장 변경을 확인하며 다른 창의 저장과 충돌하면 **최신 설정 불러오기**로 다시 읽을 수 있습니다. 활성화에 따라 분석 모델 다운로드나 색인 작업이 시작될 수 있습니다.

시트 아래 **설정에서 모두 보기**는 설정 페이지의 같은 소제목으로 이동합니다. 페이지 연결을 켜면 어시스턴트가 설정 열기·조회·초안 변경을 도울 수 있고, 저장은 기존 검토 카드로 확정합니다. 서버 인증은 **생성 엔진**, LLM 연결은 **AI 연결**에서 관리합니다.

## 설정 섹션 요약

| 탭 | 주요 기능 | 먼저 볼 때 |
| --- | --- | --- |
| 내 설정 (`mine`) | 내 사용자 프로필·페르소나, 플래그 | 대화에 쓸 내 정보 |
| 공용 화면 테마 (`general`) | 공용 기본 언어·표시·테마·밀도 | 화면 기본값 |
| 라이브러리 (`library`) | 유사도, 감시 폴더·백업 소스, 메타데이터 | 이미지 탐색·추출 |
| 미디어 처리 (`media`) | 이미지 저장, 썸네일, 영상 최적화 | 저장 정책 |
| 생성 엔진 (`generation`) | NovelAI 인증, ComfyUI 서버, 실행 간격, 예약 작업 | 생성 연결·실행 정책 |
| AI 연결 (`llm`) | 연결·모델 슬롯, 사용량, 프롬프트, 기록 | LLM 연결·모델 변경 |
| 채팅 (`chat`) | 채팅 사용, 기억, 도구 호출, 웹 검색, 관리자 공용 플래그 원본 | 모든 프로필의 동작 |
| 게시판·지식 (`posts`) | 일반, 주제 관련도, 지식 품질 | 게시판 자동화 |
| 자동 분석 (`auto`) | AI 런타임, 작가 분석, 태거, 임베딩, 평가 | 자동 분석 |
| 계정·권한 (`accounts`) | 계정, 권한 그룹, 복구 정보 | 접근 관리 |
| 플러그인 (`plugins`) | 설치·활성화·관리 | 확장 기능 |
| 시스템 (`system`) | MCP, 안전·정리 | 서버 동작 |
| 유지보수 (`maintenance`) | 스캔·검증·재추출·재매칭 | 기존 데이터 정비 |

섹션 안에서는 탭 대신 소제목과 위쪽 목차 링크를 사용합니다. `?section=llm&group=connections`처럼 소제목에 직접 연결하고, `&setting=행ID`로 특정 행을 찾아 강조할 수 있습니다. 설정 검색과 Ctrl K의 **설정** 검색은 같은 이름·설명·동의어를 사용하며 접힌 고급 항목도 찾습니다. 고급 항목은 해당 그룹 끝의 **고급 설정 n개**를 펼칩니다. 프로필 편집 페이지는 섹션마다 **고급**을 접어 두고, 다른 편집 대화 상자의 고급 스위치는 그대로입니다.

설정 저장 바의 저장은 Ctrl/⌘+S로도 실행합니다. 여러 변경을 저장하는 동안에는 설정 초안 입력과 어시스턴트 초안 변경이 잠시 멈추며, 진행 중인 작업 취소와 별도 작업은 계속할 수 있습니다.

공용 설정은 초안을 시작한 섹션의 저장값이 다른 창에서 바뀌면 저장을 거부하고 초안을 유지합니다. 월페이퍼 프리셋·일정과 LLM 프롬프트·시스템 프롬프트·JSON 양식도 저장 또는 삭제할 때 시작한 목록을 확인합니다. 월페이퍼 편집 중 같은 화면의 공용 테마 설정을 저장해도 프리셋 초안은 유지됩니다. 월페이퍼 초안은 새로고침 후에도 원래 프리셋을 기억해, 다른 곳에서 바뀐 프리셋에 덮어쓰지 않습니다. 충돌하면 최신 프리셋을 열거나 **다른 이름으로 저장**하세요. 이전 버전에서 만든 수정된 초안은 원래 프리셋을 확인할 수 없을 때 새 이름으로 저장해야 합니다. 라이브 지정은 목록을 다시 저장하지 않습니다.

채팅 프로필은 `/characters?view=profiles`, 도구·생성·판단 프리셋은 `/chat/resources?tab=presets`, 표시 블록은 `tab=blocks`, 로어북은 `tab=lorebooks`, 루틴은 `tab=routines`로 이동했습니다. 옛 채팅 설정의 `view=profiles|resources|routines|mine` 주소는 새 위치로 연결됩니다. 관리자가 만든 플래그 원본은 공용 저장값이므로 **앱 관리 → 채팅 → 공용 플래그**(`section=chat&group=flags`)에 남고, 개인 사본만 내 설정에서 바꿉니다.

## 앱 마크

**설정 → 공용 화면 테마 → 테마 → 앱 마크**에서 상단 CoNAI 옆의 이미지를 바꿉니다.

1. **PC에서 선택** 또는 **내부 이미지**로 한 장을 고릅니다. PNG·JPG·WebP·GIF·AVIF를 20MB, 1,600만 화소까지 지원합니다.
2. 편집창에서 **전체 넣기 / 영역 자르기**, 드래그 위치 이동, 확대, 90도 회전, 좌우 반전을 조절합니다. 체크무늬는 투명 영역이며, 아래에서 상단에 표시될 작은 크기를 미리 볼 수 있습니다.
3. **등록**을 누르면 투명도를 유지한 128×128 PNG로 저장하고 상단에 바로 반영합니다. 설정 저장 바를 다시 누를 필요는 없습니다. 움직이는 이미지는 정지 이미지로 저장합니다.

**편집**으로 현재 마크를 다시 조정하고, **기본 마크**로 복원할 수 있습니다. 등록·복원은 관리자 권한으로 모든 사용자에게 적용됩니다. 내부 이미지 원본은 수정하지 않으며, 나중에 원본을 삭제해도 등록한 마크는 유지됩니다. 다른 테마 항목의 저장하지 않은 변경도 유지됩니다.

페이지 연결을 켠 어시스턴트는 현재 마크 또는 내부 이미지 해시로 편집창을 열고, 위치·확대·회전·반전을 초안으로 조절할 수 있습니다. 등록과 기본 마크 복원은 기존 저장 검토 카드를 통해 확정합니다.

## 자동 분석

주요 작업:

- AI 런타임: 태거·Kaloscope·임베딩과 이미지 편집기의 AI 지우기가 쓰는 Python 환경을 앱이 직접 설치합니다. GPU와 드라이버를 보고 빌드(CPU, CUDA 12.6/13.0/13.2)를 자동으로 고르며, 새 환경은 검증을 통과해야 바뀌고 실패하면 이전 환경이 그대로 남습니다. 직접 설치한 Python을 쓰려면 Python을 "직접 지정"으로 바꿉니다.
- Kaloscope 3 설정과 상태 확인, 화풍 벡터 저장, 이전(v2) 결과 다시 추출
- 태거 설정: WD v3 모델 3종, 또는 GPU에서만 고를 수 있는 PixAI v1.0
- 임베딩(EmbeddingGemma 2, CPU): 채팅 기억 회상, 로어북 의미 발동, 채팅 기록 검색, 파일·회의록 검색, 이미지 임베딩을 하나씩 켭니다. 기본은 꺼져 있습니다. 이미지 임베딩은 라이브러리를 CPU로 장당 약 1초씩 색인하므로 큰 라이브러리에서는 시간이 오래 걸립니다. AI 런타임이 설치돼 있으면 켜는 즉시 모델(약 1.5GB)을 내려받아 올려 두고, 받는 중·오류(5분 쉬었다가 다시 시도)는 상태 표시와 색인 줄의 안내로 보입니다. 설치된 transformers / sentence-transformers가 요구 버전보다 낮으면 AI 런타임 재설치를 안내합니다.
- 평가 가중치 설정
- 평가 등급 설정
- 해시 기준 테스트 이미지 확인
- 랜덤 이미지로 자동 추출 테스트

업로드 페이지의 자동 추출/작가 추출과 이미지 상세의 자동/작가 프롬프트 표시에 연결됩니다.

## 미디어 처리와 생성 엔진

미디어 처리(이미지 저장·썸네일·영상 저장)의 주요 항목:

- 기본 저장 포맷: 원본 유지, PNG, JPEG, WebP
- 품질
- 리사이즈와 최대 크기
- 매번 팝업 확인 여부
- 생성 첨부/생성 입력 편집/라이브러리 편집본/업로드/워크플로 출력 적용 여부
- 영상 저장(H.264 MP4 최적화)

생성 엔진의 주요 항목:

- NovelAI 인증: 서버 토큰 연결과 연결 상태(구독·Anlas)
- ComfyUI 서버: 서버 등록·연결 확인·삭제, CoNAI Helper 커스텀 노드 다운로드
- 실행 간격: NovelAI·Codex 동시 실행 수와 구간·간격
- 예약 작업: 예약 동시 실행 수와 사용자 대기열이 있을 때의 처리

생성 큐가 너무 빠르게 몰리거나 외부 서비스 제한이 걱정되면 생성 텀 값을 보수적으로 잡습니다.

## 채팅으로 설정하기

1:1 채팅에서 **현재 페이지 연결**을 켜면 모델이 열린 설정 탭을 읽고 도와줍니다. 자세한 범위는 [채팅 › 현재 페이지 읽기와 입력 보조](./CHAT.md#현재-페이지-읽기와-입력-보조)를 봅니다.

- 입력은 초안에만 채우고, 저장·설치·스캔처럼 무언가를 바꾸는 작업은 카드로 제안합니다. **검토한 내용 저장**을 눌러야 진행합니다.
- 자동 탭의 AI 런타임 설치·재설치, Kaloscope 예전 결과 재추출, 시스템 탭의 HTTP MCP 켜기·끄기, 유지보수 탭의 전체 스캔·파일 검증·메타데이터 재추출도 카드로 제안할 수 있습니다.
- LLM 탭의 대표모델 대상·프리셋·답변 진단·외부 MCP 서버 켜기와 범위, 채팅 탭의 기억·웹 검색 설정과 사용자 프로필·플래그·루틴도 같은 방식입니다.
- 비밀 값(LLM 키, 외부 MCP 주소·헤더·환경 변수, MCP 키)은 모델이 읽거나 쓰지 않습니다. 계정·권한은 읽기만 합니다.

## 변경 후 확인 순서

1. 설정 저장 버튼을 눌렀는지 확인합니다.
2. 관련 화면을 새로고침합니다.
3. 스캔/추출/생성처럼 큐가 필요한 작업은 로그나 상태를 확인합니다.
4. 권한 변경은 다른 계정 또는 `/access`에서 확인합니다.
5. 저장 경로/삭제 보호 변경은 테스트 파일 하나로 먼저 확인합니다.
