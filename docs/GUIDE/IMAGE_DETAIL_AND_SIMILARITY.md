# 이미지 상세와 유사도 검사

이미지 상세는 한 파일의 미리보기, 메타데이터, 프롬프트, 유사 이미지를 확인하는 화면입니다.

## 관련 페이지

| 목적 | 경로 |
| --- | --- |
| 상세 페이지 | `/images/:compositeHash` |
| 메타데이터 편집 | `/images/:compositeHash/metadata` |
| 홈 피드 | `/` |
| 유사도 기본 정책 | `/settings` → 일반 설정 |

`compositeHash`는 CoNAI가 파일을 식별할 때 사용하는 복합 해시입니다. 홈, 업로드 결과, 그룹, 생성 이력에서 상세로 이동할 수 있습니다.

- 정지 이미지는 **픽셀이 완전히 같을 때만** 같은 이미지로 묶입니다. 같은 파일을 여러 폴더에 두거나, 무손실로 포맷을 바꾸거나(PNG ↔ 무손실 WebP), 메타데이터만 고친 경우는 하나로 묶입니다. 색만 바꾼 변형, JPEG 재저장, 크기를 줄인 사본은 따로 저장되고 아래 **중복 이미지**·유사 이미지 검색에서 찾을 수 있습니다.
- 동영상과 움짤(GIF)은 파일 내용 자체로 식별합니다.
- 예전 버전에서 이미 하나로 묶인 이미지는 그대로 둡니다. 새로 들어오는 파일부터 이 기준이 적용됩니다.

## 상세 화면에서 보는 것

| 영역 | 설명 |
| --- | --- |
| 미디어 미리보기 | 이미지/비디오를 크게 표시합니다. |
| 메타데이터 | 복합 해시, 크기, 파일 크기, 모델, 파라미터, 원본 경로를 표시합니다. |
| 추출 프롬프트 | 긍정/부정 프롬프트를 표시하고 복사할 수 있습니다. |
| 자동 프롬프트 | 자동 태그 결과를 등급/캐릭터/일반 태그로 나눠 보여줍니다. |
| 작가 프롬프트 | Kaloscope 작가 후보와 링크를 표시합니다. |
| 중복 이미지 | 같은/매우 가까운 해시를 가진 항목을 보여줍니다. |
| 유사 이미지 | 이미지 해시·색상 기준 유사 항목을 보여줍니다. |
| 텍스트 유사 | 프롬프트 텍스트 기준 유사 항목을 보여줍니다. |
| 내용 유사 | 그림에 담긴 내용(인물, 옷, 장면)이 비슷한 항목을 보여줍니다. 이미지 임베딩이 켜져 있고 이 이미지가 색인된 뒤에만 보입니다. |
| 화풍 유사 | 그림체가 비슷한 항목을 Kaloscope 3의 화풍 벡터로 찾습니다. 이 이미지에 Kaloscope가 실행된 뒤에만 보입니다. |

| 버튼 | 기능 |
| --- | --- |
| 뒤로 | 홈 또는 이전 상세 진입 지점으로 돌아갑니다. |
| 새로고침 | 현재 상세 데이터를 다시 불러옵니다. |
| 메타데이터 편집 | `/images/:compositeHash/metadata`로 이동합니다. 정적 이미지에서만 사용합니다. |

| 그룹 추가 | 현재 이미지를 커스텀 그룹에 추가합니다. |
| 다운로드 | 원본 또는 렌더 가능한 파일을 내려받습니다. |

## 프롬프트 표시 방식

추출 프롬프트에는 두 가지 표시 방식이 있습니다.

- **Plain**: 원본에 가까운 프롬프트 텍스트를 그대로 표시합니다.
- **Group**: CoNAI 프롬프트 그룹 기준으로 태그를 묶어 표시합니다.

Group 표시에서는 분류 깊이를 조절하거나 Danbooru를 루트 그룹처럼 취급하는 옵션을 사용할 수 있습니다. 이 값은 브라우저 로컬 설정으로 저장됩니다.

태그는 쉼표·줄바꿈·`BREAK`로 나눕니다. `(a, b:1.2)`처럼 쉼표를 감싼 가중치 괄호는 `(a:1.2)`, `(b:1.2)`로 태그마다 나눠 보여 주고, 검색·그룹 분류에는 가중치를 뺀 태그를 씁니다. 짝 없는 닫는 괄호와 그 앞의 `:0.5`, 빈 괄호처럼 깨진 문법은 태그에서 빼고, 닫히지 않은 괄호는 괄호만 걷어 냅니다. 복사 버튼은 원문을 그대로 복사합니다. 같은 규칙이 프롬프트 수집과 입력 추천에도 쓰입니다.

### 레이아웃(BBOX) JSON 프롬프트

MOSS-Image처럼 프롬프트가 `summary`와 `items[{label, caption, text, bbox}]`로 된 JSON이면 태그로 쪼개지 않고 메인 프롬프트와 영역별 프롬프트로 나눠 보여 줍니다. 프롬프트 제목줄의 전환 버튼으로 고릅니다.

- **칩**: 메인 프롬프트(`summary.caption`·meta)와 번호가 붙은 영역 카드(종류·caption·렌더링 텍스트)를 쉼표 기준 칩으로 나눠 보여 주며 칩으로 검색 필터를 추가할 수 있습니다. 그룹 분류는 적용하지 않습니다.
- **전체**: 원문 JSON을 들여쓰기해 그대로 보여 줍니다. 영역으로 나누지 않은 전체 프롬프트를 볼 때 씁니다.

영역 카드에 마우스를 올리거나 포커스하면 보고 있는 이미지 위에 해당 영역 박스가 표시되고, 프롬프트 섹션의 썸네일 지도(최대 높이 안에서 가능한 크게, 가운데 정렬)에서도 같은 영역이 강조됩니다. 썸네일의 박스에 올려도 반대로 카드가 강조됩니다. 박스 좌표는 `bbox_format`(`yxyx`·`xyxy`)과 `bbox_coord_space`(`abs_centralized`·`abs`)를 따르고, 이미지 크기를 알 수 없거나 다른 좌표계면 박스 없이 카드만 보여 줍니다.

## 자동 프롬프트와 작가 프롬프트

자동 프롬프트 영역은 자동 태그 결과를 다음처럼 분리합니다.

- Rating
- Character
- General tags

일반 태그는 Danbooru 링크로 열 수 있으며, 복사 버튼으로 자동 태그 텍스트를 가져올 수 있습니다.

작가 프롬프트 영역은 Kaloscope 결과를 표시합니다. 작가 링크 템플릿은 상세 화면의 작가 설정 버튼 또는 `/settings` → 자동 설정에서 조정합니다.

## 유사/중복 검사 실행

유사도 검사는 두 방식으로 실행됩니다.

| 방식 | 설명 |
| --- | --- |
| 수동 | 상세 화면에서 **유사/중복 검사** 버튼을 누릅니다. |
| 자동 | `/settings` → 일반 설정의 유사/중복 검사 정책이 자동 실행이면 상세 열 때 실행됩니다. |

검사는 이미지 로드가 안정화된 뒤 실행됩니다. 정적 이미지가 아닌 비디오/애니메이션 항목은 일부 유사도 영역이 제한될 수 있습니다.

## 유사도 탭

| 탭 | 기준 |
| --- | --- |
| 이미지 | perceptual hash, dHash, aHash, 색상 유사도 옵션 기준 |
| 텍스트 | 긍정/부정/자동 프롬프트의 텍스트 유사도 기준 |
| 내용 | EmbeddingGemma 2 이미지 임베딩의 코사인 유사도 기준 |
| 화풍 | Kaloscope 3 화풍 벡터의 코사인 유사도 기준 |

내용·화풍 섹션은 각자 검사 버튼으로 실행하며, 상단 **유사/중복 검사**나 자동 검사 정책을 쓰면 다른 섹션과 함께 실행됩니다. 결과 수는 이미지 유사도의 결과 줄 수 설정을 따릅니다.

채팅에 상세 화면을 연결하면 채팅은 이 이미지의 자동 태그(태거 태그, PixAI의 작가·메타 태그, Kaloscope 작가 추정)와 내용·화풍 섹션을 쓸 수 있는지, 열어 둔 섹션의 결과와 점수를 읽습니다. 섹션을 열지 않았어도 채팅은 `find_similar_images` 도구로 내용 유사·화풍 유사 결과를 직접 찾습니다.

설정 권한이 있는 계정은 상세 화면의 유사도 설정 패널에서 임계값, 결과 수, 가중치, 메타데이터 필터, 프롬프트 유사도 가중치를 바로 조정할 수 있습니다.

## 점수 해석

유사 카드에는 점수 배지가 표시됩니다.

- 중복 이미지는 중복/해시 기준으로 먼저 분리됩니다.
- 이미지 유사도는 설정한 해시·색상 가중치에 따라 달라집니다.
- 텍스트 유사도는 프롬프트 필드별 가중치와 임계값에 따라 달라집니다.
- 내용·화풍 점수는 코사인 유사도 × 100이며 해시 점수와 척도가 달라 한 가지 색으로 표시합니다.

결과가 너무 많으면 임계값을 높이거나 결과 수를 줄입니다. 결과가 너무 적으면 임계값을 낮추고 색상/프롬프트 가중치를 조정합니다.

## 상세이 비어 있거나 느릴 때

1. 원본 파일 경로가 존재하는지 확인합니다.
2. 썸네일/렌더 파일이 아직 처리 중인지 확인합니다.
3. 새로고침 버튼을 눌러 DB 상태를 다시 불러옵니다.
4. 대량 파일 스캔 중이면 처리가 끝날 때까지 기다립니다.
5. 권한 때문에 상세 접근이 막히는지 `/access`에서 확인합니다.

## 이미지 편집기 사용법

- **시작·레이어**: 원본 레이어가 선택되고 잠금은 풀려 있어. 빈 레이어는 자동으로 만들지 않아. `+`로 추가해. 레이어 ⋯에서 텍스트 레이어도 이름을 바꾸거나 위·아래로 옮길 수 있어. 눈 아이콘은 화면 표시만 바꾸고 실행 취소 기록이나 변경 표시에 남지 않아. 불투명도는 마스크에도 쓸 수 있고, 마스크의 표시 농도만 바뀌어 NAI로 보내는 마스크 형태는 그대로야.
- **빈 레이어·잠금**: 비어 있는 픽셀을 복사·잘라내기·삭제·보정하려 하면 `빈 레이어야` 알림에서 원본을 선택할 수 있어. 잠기거나 숨겨진 레이어(마스크 포함)는 알림에서 잠금을 풀거나 다시 보여.
- **선택·이동**: 선택 도구로 기존 선택 안쪽을 끌면 픽셀을 떠 있는 조각으로 들어 올려. `Ctrl+A` 뒤 끌면 레이어 전체를 옮길 수 있어. 방향키는 선택 영역이나 떠 있는 조각을 1px, Shift와 함께 누르면 10px 옮겨. ✓/Enter는 들어 올린 조각을 원래 레이어에, 붙여넣은 조각은 새 레이어에 적용해. 들어 올리기는 클립보드를 바꾸지 않고, 적용 전까지 원래 픽셀도 그대로 남아 있어. Esc·Ctrl+Z·Delete나 조각 버리기로 취소하면 원래 모습으로 돌아와. 적용한 이동은 실행 취소 한 번으로 되돌려. 잘라내기·다시 들어 올리기는 기존 조각을 먼저 적용해.
- **선택 도구 옵션**: 전체 선택·선택 반전·선택 영역 채우기가 있어. 채우기는 현재 브러시 색을 쓰고 `Alt+Backspace`로도 실행해. 브러시·지우개·마스크는 선택 안에만 그려져. Shift+클릭하면 마지막 획 끝에서 직선을 그려.
- **크기·색**: 브러시와 텍스트 크기, 외곽선 수치는 직접 입력할 수 있어. 브러시 최대 크기는 1000px이고 슬라이더는 작은 크기를 세밀하게 골라. 도구 옵션 줄에도 색 선택이 있고 확정한 최근 색 8개를 편집기를 닫기 전까지 기억해. 스포이드로 색을 고르면 이전 그리기 도구로 돌아와. 투명한 픽셀은 알림만 보여 줘.
- **AI 지우기**: 지울 곳을 여러 번 칠한 뒤 영역 아래 ✓로 실행해. ✕는 칠한 영역을 비우고 실행 중에는 취소해. 실행 전·중에는 저장할 수 없어. 결과는 AI 지우기 레이어에 들어가. AI 런타임과 애니·만화 LaMa 모델이 필요하고 첫 실행 때 모델 약 200MB를 내려받아. 실패하면 짧은 알림을 보여 줘.
- **자르기·이미지 크기**: 자르기 상자 아래에 실시간 너비×높이와 ✓/✕가 있어. 적용·취소하면 이전 도구로 돌아와. 상자가 문서 전체와 같으면 변경이나 실행 취소 기록이 생기지 않아. 저장할 때 달라진 자르기도 적용돼. 하단 이미지 크기(휴대폰은 ⋯)에서 실제 문서 크기를 확인하고 너비·높이와 비율 잠금을 바꿀 수 있어. 입력한 크기가 브라우저 한도를 넘으면 안내가 보여. 적용할 때만 한 변 최대 4096px, 전체 최대 16,777,216픽셀 안으로 줄여. 실행 취소로 복원할 수 있어.
- **보기·변형**: 휠은 확대·축소야. 확대율 메뉴에서 맞춤·50·100·200·400%를 골라. 손 도구를 더블클릭해도 맞춰져. 하단과 휴대폰 ⋯에 좌·우 90° 회전, 좌우·상하 뒤집기가 있어.
- **보정·비교**: 보정 슬라이더 이름을 더블클릭하면 해당 값만 0으로 돌아가. `되돌리기`는 보정 미리보기를 버리고 `적용`은 저장해. `\`를 누르는 동안 처음 연 원본을 비교하고, 하단 눈 아이콘으로 비교를 켜고 끌 수도 있어. 텍스트 위에 칠하거나 보정하면 픽셀로 바뀌었다는 알림이 나와. 실행 취소로 텍스트를 복원해.
- **저장**: 변경이 없으면 저장 버튼은 꺼져 있고 변경이 있으면 하단에 표시돼. 저장 옵션 창을 열어도 레이어는 유지돼. 옵션을 취소하면 편집기로 돌아오고, 성공해야 편집기가 닫혀. 라이브러리 저장 알림의 `열기`로 편집본을 열어. NAI Source/Mask 편집에서는 기존처럼 생성 폼에 결과를 넣어.
- **페이지 어시스턴트**: 화면 연결 중 `image_editor.*` 작업으로 도구·브러시·직선·선택 이동/채우기·레이어 이름/순서/불투명도·확대율·크기·비교·보정·AI 지우기 적용/취소·단축키를 조작할 수 있어. 기존 초안/저장 검토 등급은 그대로야. 저장은 검토 카드를 통해 같은 저장 경로로 실행해. 편집기 닫기는 직접 해.
