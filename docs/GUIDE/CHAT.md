# 채팅 (Codex · API LLM)

채팅 프로필과 대화하면서 CoNAI를 조작합니다. 프로필마다 엔진을 고릅니다.

- **Codex**: 서버에 연결된 Codex CLI. 대화 기억은 Codex가 직접 관리합니다.
- **API LLM**: 설정의 LLM 연결(OpenAI 호환, Ollama). 로컬 엔진(예: Strata, LM Studio)이나 외부 API를 쓸 수 있고, 대화 기억(최근 턴·토큰 한도·요약)은 프로필에서 정합니다.

두 엔진 모두 CoNAI MCP 도구만 쓸 수 있어서, 이미지 검색·메타데이터 조회·NAI/ComfyUI/Codex 생성·워크플로우 실행·그룹 정리를 말로 요청할 수 있습니다.

## 위치

- **패널**: 상단 헤더의 채팅 아이콘을 누르면 어느 페이지에서든 오른쪽 패널로 열립니다. 휴대폰 폭에서는 전체 화면으로 열리고 뒤로가기로 닫힙니다.
- **전체 페이지**: `/#/chat`. 패널의 "전체 페이지로 열기"로 넘어가고, "패널로 접기"로 돌아옵니다. 왼쪽에 채팅 목록이 나옵니다.

채팅이 켜져 있고 계정에 채팅 권한이 있을 때만 헤더에 채팅 아이콘이 보입니다. 예전 주소 `/#/generation?tab=chat`은 `/#/chat`으로 넘어갑니다. 페이지를 옮기거나 패널과 전체 페이지를 바꿔도 진행 중인 답변은 끊기지 않습니다.

## 설정

설정 → **채팅**. 바꾼 값은 바로 적용됩니다.

- **채팅 사용**: 모든 프로필의 전체 스위치입니다.
- **채팅 프로필**: 목록에서 켜고 끄고, 연필 아이콘으로 편집합니다.
- **LLM 연결**(설정 → **LLM** 탭): 어디에 어떻게 접속할지만 정합니다. 이름, 종류(OpenAI 호환·Ollama), 주소, API 키, 기본 모델(프로필·노드에서 모델을 비웠을 때), 요청 제한 시간. 온도·출력 길이·추론 같은 생성 옵션은 연결이 아니라 **프로필**에서 정합니다. 워크플로우의 LLM 호출 노드도 프로필을 골라 같은 옵션으로 실행합니다.

### 채팅 프로필 항목

| 항목 | 설명 |
| --- | --- |
| 이름·아바타 | 채팅에 표시되는 이름과 그림. 아바타는 정사각형으로 잘라 작게 저장합니다. |
| 짧은 소개 | 새 채팅 프로필 카드에 표시할 한 줄 소개(최대 200자). |
| 엔진 | API LLM 또는 Codex. |
| LLM 연결·모델 | API LLM. 모델은 연결이 알려 주는 목록에서 고르고, 비우면 연결의 기본 모델을 씁니다. |
| 온도·최대 출력 토큰 | API LLM. 비우면 요청에 넣지 않아 서버 기본값을 씁니다. 최대 출력 토큰은 추론과 답변을 합친 한도입니다. |
| 추론 강도·추론 토큰 예산 | API LLM. `reasoning_effort`(none·low·medium·high)와 `reasoning_budget_tokens`로 보냅니다(LiteLLM·OpenAI 호환 형식, Ollama는 `think`). 비우면 보내지 않습니다. 대화 요약은 추론을 끄고(none) 보냅니다. |
| 고급: 추가 파라미터 (JSON) | API LLM. 서버마다 다른 옵션을 요청 본문에 그대로 붙입니다(예: `{"chat_template_kwargs": {"enable_thinking": true}}`). `model`, `messages`, `stream`, `tools`는 덮어쓸 수 없습니다. |
| 이미지를 볼 수 있는 모델 | API LLM. 켜면 `view_images` 도구로 받은 이미지를 모델에게 그대로 보여 줍니다. 비전을 지원하지 않는 모델에서 켜면 요청이 실패할 수 있습니다. |
| Codex 모델·추론 강도 | Codex. 비우면 서버 CLI 기본값을 씁니다. 모델이 지원하지 않는 추론 강도는 저장되지 않습니다. |
| 시스템 프롬프트 | 대화마다 지시문으로 들어갑니다. `{{char}}`는 프로필 이름으로 바뀝니다. |
| 섹션 | **섹션 추가**로 제목과 내용을 직접 만듭니다(예: 캐릭터, 세계관, 내 페르소나). 접고 펼칠 수 있고, 스위치로 잠시 빼 둘 수 있습니다. 일반 텍스트 섹션은 시스템 프롬프트 뒤에 `## 제목`으로 붙습니다. |
| 섹션 형식: 대화 예시 | `사용자:` / `{{user}}:` 와 `{{char}}:` / 프로필 이름으로 시작하는 줄이 있으면, API LLM에는 지시문 대신 **실제 user/assistant 대화**로 넘겨 말투를 더 잘 따라 하게 합니다(예시라는 안내가 지시문에 붙습니다). 화자 표시가 없거나 Codex 프로필이면 텍스트로 붙습니다. |
| 첫 인사말 | 새 채팅의 첫 메시지로 저장됩니다(지시문에는 들어가지 않습니다). |
| 프리셋 불러오기 | 책 아이콘. 설정 → **LLM** 탭의 프리셋을 불러옵니다. 시스템 프롬프트 프리셋은 시스템 프롬프트를 바꾸고(내용이 있으면 확인 후), 프롬프트 프리셋은 같은 이름의 섹션으로 추가됩니다. 처음 실행하면 캐릭터 롤플레이 기본, CoNAI 도우미, 이미지 프롬프트 작가, 롤플레이 출력 형식 같은 기본 프리셋이 한 번 들어가며, 이후에는 자유롭게 고치거나 지울 수 있습니다. |
| 프롬프트 미리보기 | 눈 아이콘. 모델이 받는 지시문·예시 대화·도구 목록과 토큰 추정치(프롬프트, 도구 설명, 합계)를 보여 주고, 컨텍스트 길이를 넘으면 표시합니다. |
| 꾸미기: 글꼴 | 이 프로필 채팅의 글꼴(기본·명조·고정폭). |
| 꾸미기: 배경 이미지 | 채팅 뒤에 깔리는 그림. 긴 변 1600px로 줄여 저장하고, 어둡게·흐리게 정도로 글이 잘 읽히게 맞춥니다. |
| 꾸미기: 롤플레이 글자색 | 켜면 `"대사"`, `*묘사*`, `'속마음'`을 각각 다른 색으로 보여 주고(대사를 비우면 기본 글자색), 모델에게 이 표기법을 쓰라고 지시문으로 알려 줍니다. 아래 예시 줄에서 바로 확인할 수 있습니다. |
| 꾸미기: 등장인물 | 프로필 말고도 답변에 함께 나오는 캐릭터(최대 8명). 이름·아바타·이름 색을 정합니다. 모델은 다른 캐릭터가 말할 때 `[이름]` 줄로 화자를 바꾸라고 안내받고, 채팅은 그 줄에서 답변을 나눠 캐릭터마다 아바타와 이름을 따로 보여 줍니다. 등록되지 않은 이름의 `[…]` 줄은 그대로 글로 둡니다. |
| 꾸미기: 이모티콘 그룹 | 연결할 [LLM 이모티콘 그룹](GROUPS_GUIDE.md#llm-이모티콘-그룹)을 고릅니다. 고른 순서가 우선순위라서, 두 그룹에 같은 키워드가 있으면 먼저 고른 그룹의 이미지가 쓰입니다. 모델은 지시문으로 키워드 목록(최대 150개)과 `&*키워드*&` 표기법을 안내받습니다. |
| 꾸미기: 표시 블록 | 상태창·카드 같은 꾸민 블록. 아래 [표시 블록](#표시-블록) 참고. |
| CoNAI 도구(MCP) 사용·권한 | 조회·생성·정리 중에서 고릅니다. 실제로는 계정의 채팅 도구 권한과 겹치는 범위만 쓸 수 있습니다. |
| 도구 고급 설정 | 펼쳐서 **도구를 하나씩** 고를 수 있습니다. 도구 설명이 프롬프트를 크게 차지하므로(전체 약 5천~1만 토큰), 컨텍스트가 짧은 모델은 필요한 도구만 고르면 가벼워집니다. API LLM은 도구 호출 반복 한도(한도에 닿으면 도구 없이 답함)와 도구 결과 최대 길이도 정합니다. |
| 참고할 최근 턴 수 | API LLM. 요청마다 보내는 최근 대화(사용자 메시지 하나와 그 답변이 한 턴). |
| 컨텍스트 길이(토큰) | API LLM. 비우면 제한이 없습니다. 지정하면 시스템 프롬프트·요약·도구 설명·답변 몫을 뺀 만큼만 최근 턴을 보냅니다. 토큰 수는 서버가 알려 주는 실제 사용량으로 프로필마다 보정합니다. 컨텍스트가 짧은 모델에 맞춰 줄입니다. |
| 대화 요약·요약 시작 | API LLM. 켜면 창 밖으로 밀려난 턴(턴 수나 토큰 한도로 빠진 턴)이 "요약 시작" 수만큼 쌓일 때마다 요약에 합쳐 다음 요청에 같이 보냅니다. |
| 요약 연결·모델·프롬프트 | 비우면 대화 모델과 기본 요약 프롬프트를 씁니다. 가볍고 빠른 모델로 요약하게 할 수 있습니다. |

이전 버전의 Codex 채팅 설정(사용 여부, MCP 권한, 실행 모델, 추론 강도)은 처음 채팅을 열 때 **Codex** 프로필로 옮겨지고, 기존 Codex 채팅도 그 프로필에 연결됩니다.

### 표시 블록

모델은 **값만** 쓰고, 모양은 프로필에 미리 만든 템플릿이 정합니다. 그래서 작은 모델도 꾸민 화면을 낼 수 있고, 모델이 쓴 내용이 코드로 실행되지 않습니다.

1. **표시 블록 추가**를 누르면 상태창 예시가 채워진 블록이 생깁니다.
2. **이름**은 모델이 쓰는 코드 블록 이름입니다. 이름이 `status`면 모델은 ` ```status ` 블록 안에 JSON 값을 씁니다.
3. **언제 쓰는지**와 **예시 값(JSON)**은 지시문에 그대로 들어가 모델에게 형식을 알려 줍니다. 예시 값은 아래 미리보기에도 쓰입니다.
4. **HTML 템플릿**에 값이 들어갈 자리를 표시하고, **CSS**로 꾸밉니다.

| 템플릿 문법 | 뜻 |
| --- | --- |
| `{{name}}`, `{{a.b}}` | 값. 목록은 쉼표로 이어 붙입니다. |
| `{{#each items}}…{{/each}}` | 목록을 반복합니다. 안에서 `{{.}}`은 항목 자체, `{{field}}`는 항목의 필드입니다. |
| `{{#if field}}…{{else}}…{{/if}}` | 값이 있을 때(빈 값·0·false가 아닐 때)만 보여 줍니다. |

- 값은 글자로만 들어갑니다. 모델이 값에 HTML을 써도 태그가 아니라 글자로 보입니다.
- 스크립트, 이벤트 속성(`onclick` 등), 프레임, 폼, `javascript:` 주소는 템플릿에 있어도 지워집니다.
- CSS는 그 블록 안에만 적용돼서 앱 화면에 영향을 주지 않습니다.
- 값이 JSON으로 읽히지 않으면(답변이 아직 오는 중일 때 포함) 평범한 코드 블록으로 보입니다.

### 권한

설정 → 계정·권한의 권한 그룹에서 **채팅** 묶음으로 부여합니다. 관리자는 모두 가집니다.

| 권한 | 설명 |
| --- | --- |
| Codex 프로필로 채팅 | 서버에 로그인된 Codex 계정 사용량을 함께 씁니다. |
| API LLM 프로필로 채팅 | |
| 채팅 도구: 조회·생성·정리 | 그 계정의 채팅에서 에이전트가 쓸 수 있는 MCP 범위. 프로필 권한과 겹치는 범위만 열립니다. |

## 사용

1. 헤더의 채팅 아이콘으로 채팅을 엽니다. PC에서는 패널 왼쪽 가장자리를 끌어 폭을 바꿀 수 있습니다(더블클릭하면 기본 폭, 이 브라우저에 저장).
2. **+**로 새 채팅 화면을 엽니다. 큰 아바타, 소개, 엔진·모델, 마지막 대화 시각이 있는 프로필 카드를 고르면 새 대화를 시작합니다. 검색으로 프로필을 좁히거나 카드 아래 최근 대화 바로가기로 이어갈 수 있습니다. 패널은 한 열, 넓은 전체 페이지는 두 열입니다. + 옆 화살표는 최근 프로필 3개와 전체 보기를 엽니다.
3. 입력창에 요청을 적고 Enter로 보냅니다. 줄바꿈은 Shift+Enter입니다.
4. 답변이 실시간으로 표시됩니다. 동영상은 썸네일 자리에서 소리 없이 반복 재생되고, 뷰어에서 열면 소리와 함께 재생됩니다. 생각하는 모델은 "생각하는 중…"을 눌러 과정을 볼 수 있습니다(저장되지는 않습니다). 쓴 도구는 이름 옆에 렌치 아이콘과 횟수로 나오고, 마우스를 올리면(휴대폰은 누르면) 도구별 횟수·결과 요약 목록이 열립니다.
   답변은 마크다운으로 표시됩니다(제목, 목록, 표, 링크, 인용, 코드). 코드 블록에는 언어 표시와 복사 버튼이 있고, `html`·`svg` 블록은 눈 아이콘으로 미리 볼 수 있습니다. 미리보기는 격리된 창(sandbox)에서 돌아가서 스크립트는 실행되지만 앱이나 로그인 정보에는 접근하지 못합니다. 코드 블록 밖의 HTML은 실행하지 않고 글자로 보여 줍니다. 두 엔진 모두 이 표시 방식을 지시문으로 안내받습니다.
5. 생성하거나 찾은 이미지는 답변에 썸네일로 나옵니다. PC에서는 마우스를 올리면 크게 미리 보이고, 누르면 페이지를 떠나지 않는 이미지 뷰어가 열립니다. 뷰어에서 같은 답변의 이미지를 ← →(휴대폰은 좌우로 밀기)로 넘기고, 더블클릭으로 원본 크기를 보고, 상세 보기·다운로드를 할 수 있습니다. ESC·뒤로가기·바깥 클릭으로 닫으면 채팅으로 돌아옵니다.
6. 답변 도중 중단 버튼으로 멈출 수 있습니다.

답변 속 `&*키워드*&`는 연결된 이모티콘 이미지로 바뀝니다. 한 줄에 그것만 있으면 큰 스티커로, 문장 중간에 있으면 글자 크기만 한 이모티콘으로 보입니다. 등록되지 않은 키워드는 글자 그대로 남습니다. 이모티콘 이미지는 채팅 전용 경로로 보여 주므로 이미지 조회 권한이 없는 계정도 볼 수 있습니다.

글꼴·글자색·배경은 프로필이 정하고, 읽는 사람은 헤더의 **⋯ → 채팅 모양**에서 프로필 사진 크기, 글자 크기, 줄 간격, 이모티콘 크기(문장 속·단독 스티커), 배경 이미지 표시만 바꿀 수 있습니다. 문장 속 이모티콘을 크게 하면 그 줄의 간격이 그만큼 벌어집니다. 이 설정은 이 브라우저에만 저장되고 패널과 채팅 페이지에 함께 적용됩니다.

헤더의 **⋯ → 이미지 모아보기**는 이 채팅에 나온 이미지를 날짜별로 모아 보여 줍니다. **생성**(채팅에서 만든 이미지)과 **찾아본**(검색·조회로 본 이미지)으로 나눠 볼 수 있고, 뷰어의 "메시지로 이동"으로 그 이미지가 나온 답변으로 돌아갑니다. 목록은 저장된 대화에서 그때그때 만들기 때문에, 채팅을 지우면 함께 사라지고 이미지 자체는 라이브러리에 남습니다.

API LLM 채팅의 헤더 **⋯ → 컨텍스트**에서는 이 채팅만의 참고 턴 수와 요약 사용 여부를 바꾸고(비우거나 "프로필"을 고르면 프로필 값을 따릅니다), 지금까지의 요약을 보고 고치거나 **지금 요약**으로 바로 요약할 수 있습니다.

대화는 채팅별로 저장됩니다. 페이지를 닫아도 진행 중인 답변은 서버에서 끝까지 진행되고 저장됩니다.

긴 대화는 최근 80개 메시지부터 표시합니다. 위로 스크롤하거나 **이전 메시지**를 누르면 80개씩 더 펼쳐집니다. 이전 대화를 읽는 동안에는 새 답변이 와도 맨 아래로 강제로 이동하지 않으며, 이미지 모아보기의 **메시지로 이동**은 접힌 메시지도 펼쳐서 찾아갑니다.

API LLM 채팅에서 마지막 답변에 마우스를 올리면 **다시 생성**, 내 메시지에는 **수정** 버튼이 나옵니다. 휴대폰에서는 메시지를 탭합니다. 수정은 Enter로 저장하고 다시 답변하며, Shift+Enter로 줄바꿈, Esc로 취소합니다. 이전 턴을 수정할 때는 이후 대화를 지울지 확인합니다. 여러 답변이 있으면 **‹ 1/2 ›** 버튼으로 전환합니다.

메시지를 수정하면 그 뒤의 대화와 첨부 연결이 지워집니다. 영향을 받는 요약은 초기화되고, 다시 생성이 응답 없이 실패하면 기존 답변이 유지됩니다. 답변 전환 후 다음 요청은 선택한 답변을 사용합니다. 답변이 진행 중이면 기록 변경과 수동 요약은 409로 거절됩니다.

대화 비우기는 채팅 자체를 유지하면서 메시지·첨부 연결·요약을 초기화하고 프로필의 첫 인사말을 다시 넣습니다. 파일 보관함의 원본과 생성 이미지는 남습니다. Codex 채팅은 대화 비우기 후 새 Codex 스레드로 시작하며, 메시지 수정·다시 생성·답변 전환은 API LLM 채팅에서만 지원합니다.

예:

```text
"풍경" 그룹에 있는 이미지 중 최근 것 5장 보여줘.
NAI로 비 오는 골목 일러스트 한 장 만들어서 "채팅 테스트" 그룹에 넣어줘.
```

## 캐릭터 카드 가져오기

설정 → 채팅에서 **+ 옆 가져오기 아이콘**으로 PNG 또는 JSON 캐릭터 카드(V1/V2/V3, 최대 8MB)를 엽니다. 이름·소개·프롬프트 섹션·대화 예시·첫 인사말·로어북을 채운 편집 창이 열리고, **저장**을 누르기 전에는 프로필이 등록되지 않습니다. PNG는 128px WebP 아바타로 바뀝니다.

엔진은 API LLM, 연결은 첫 활성 LLM 연결로 선택하며 MCP는 꺼진 상태입니다. 다른 첫 인사말들도 보관하지만 새 대화에서 선택하는 기능은 후속 범위입니다. 카드 내용은 문자열로만 다루며 `{{original}}`은 제거합니다. 압축 텍스트의 해제 크기와 이미지 픽셀 수에도 제한을 둡니다.

## 로어북

프로필 편집의 **로어북**에 키워드와 설정을 등록합니다. 기본으로 최근 메시지 4개에서 키워드를 부분 일치로 찾으며, 대소문자 구분과 항상 넣기를 항목별로 설정할 수 있습니다. 낮은 순서부터 토큰 상한(기본 1024) 안에 들어가는 항목을 반영합니다. 키워드는 Enter·쉼표 또는 입력칸을 벗어날 때 칩으로 추가됩니다.

API LLM은 요약 뒤의 `관련 설정` 시스템 메시지로, Codex는 해당 턴 사용자 입력 앞의 `참고 설정`으로 받습니다. 프롬프트 미리보기에는 항상 넣기 항목만 표시됩니다. 격리 환경에서 한글·영문 부분 일치, 대소문자, 검색 범위, 순서·상한과 미리보기 동작을 확인했습니다.

## 커맨드·검색·내보내기

입력창에 `/`를 쓰면 커맨드가 나옵니다. ↑·↓로 고르고 Enter로 실행하거나 Tab으로 입력합니다. Esc로 목록을 닫습니다. `//help`처럼 슬래시를 두 번 쓰면 `/help`라는 일반 메시지로 보냅니다. 커맨드 자체는 대화 기록에 저장하지 않습니다.

| 커맨드 | 동작 |
| --- | --- |
| `/new [프로필 이름]` | 지정한 프로필로 새 채팅. 이름을 비우면 현재 프로필. |
| `/clear` | 확인 후 대화를 비우고 첫 인사말 복원. Codex 기억도 초기화. |
| `/compact` | 대화를 강제로 요약하고 이 채팅의 요약 사용을 켬. 대화에 요약 경계 표시. |
| `/retry` | 마지막 답변 다시 생성(API LLM). |
| `/edit` | 마지막 내 메시지 수정(API LLM). |
| `/export` | Markdown 또는 JSON 다운로드. |
| `/search 단어` | 내 대화 전체에서 메시지 검색. |
| `/help` | 커맨드 목록. |

헤더의 **⋯** 메뉴에는 아이콘과 함께 컨텍스트, 이미지 모아보기, 채팅 모양, 대화 비우기, 압축, 내보내기, 삭제가 있습니다. 패널과 전체 페이지에서 같은 메뉴를 사용합니다.

전체 페이지 왼쪽 검색칸 또는 `/search`로 본인 대화만 검색합니다(최대 50개). 결과를 누르면 해당 채팅과 메시지를 펼쳐서 이동·강조합니다. Markdown에는 화자·시각·첨부와 이미지 링크가, JSON에는 메시지·답변 변형·도구 호출·요약이 들어갑니다. 링크를 열 때도 원래 파일·이미지 접근 권한이 필요합니다.

## 할 수 있는 것과 없는 것

| 가능 | 불가능 |
| --- | --- |
| CoNAI MCP 도구 호출 (권한 안에서) | 셸 명령 실행 |
| | 서버 파일 읽기·쓰기 |
| | 웹 검색·브라우저 조작 |
| | 서버 Codex 설정에 등록된 다른 MCP 서버 사용 |

- 생성한 결과는 채팅한 계정의 생성 이력으로 기록됩니다.
- NovelAI 생성은 요청 한 번에 1장만 허용합니다. 2장 이상 동시 생성은 Anlas가 차감되므로, 여러 장이 필요하면 에이전트가 요청을 나눠 보냅니다.
- Codex 프로필은 서버에 로그인된 Codex 계정 하나의 사용량을 함께 씁니다.
- 작은 로컬 모델은 도구를 잘못 부르기도 합니다. 도구가 필요 없는 프로필은 MCP를 끄거나, 고급 설정에서 필요한 도구만 고르면 요청이 가벼워집니다.
- 라이브러리 검색 도구(`search_images`)는 이미지·동영상·움짤(GIF)을 구분해 찾을 수 있습니다("동영상만 찾아줘").

## 문제 해결

| 문제 | 확인 |
| --- | --- |
| 채팅 아이콘이 안 보임 | 설정에서 채팅 사용이 켜져 있는지, 계정에 채팅 권한이 있는지 확인합니다. |
| + 메뉴에 프로필이 없음 | 프로필이 켜져 있는지, 그 엔진의 채팅 권한이 있는지 확인합니다. |
| 보내기 버튼이 비활성화됨 | 입력창 위 경고를 확인합니다. Codex 로그인이 필요하면 생성 페이지의 Codex 탭에서 로그인합니다. 프로필이 지워졌거나 꺼져 있으면 새 채팅을 시작합니다. |
| "LLM 요청 실패" 오류 | LLM 연결의 주소·키·모델과, 엔진이 켜져 있는지 확인합니다. Docker로 실행 중이면 같은 PC의 엔진 주소는 `127.0.0.1` 대신 `host.docker.internal`을 씁니다. |
| "셸 도구를 끌 수 없어" 오류 | 설치된 Codex CLI가 셸 차단 옵션을 지원하지 않는 버전입니다. CLI를 업데이트합니다. |
| 도구 호출이 실패함 | 프로필의 MCP 권한과 계정의 채팅 도구 권한에 필요한 범위(생성, 정리 등)가 있는지 확인합니다. |

응답이 시작되기 전의 연결 실패, 502·503·504 또는 LiteLLM 연결 오류는 1초·2초 간격으로 최대 두 번 자동 재시도합니다. 답변이나 추론이 표시된 뒤의 오류, 인증·입력 오류(4xx), 취소·요청 제한 시간 초과는 재시도하지 않습니다. 워크플로우 LLM 호출도 같은 규칙을 사용하며, 이미 실행한 도구를 다시 실행하지 않습니다.

프로필의 스위치는 옆 글자를 눌러도 한 번씩 켜고 끌 수 있습니다. 채팅 모양 팝업은 크기·간격을 고른 뒤에도 Esc로 닫을 수 있습니다.
