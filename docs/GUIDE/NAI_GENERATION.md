# NAI 생성

NAI 탭은 NovelAI 계정으로 이미지를 생성하고, 결과를 CoNAI 생성 이력에 저장하는 화면입니다.

## 위치

`/generation?tab=nai`

## 기본 흐름

1. NAI 탭을 엽니다.
2. 로그인 버튼으로 NovelAI 계정을 연결합니다.
3. 프롬프트와 네거티브 프롬프트를 입력합니다.
4. 프롬프트 위 요약 줄의 **세부 설정**을 펼쳐 모델, 액션, 샘플링, 해상도, 샘플 수를 조정합니다.
5. 필요하면 캐릭터 프롬프트, 캐릭터 레퍼런스, Vibe 이미지를 추가합니다.
6. 생성 버튼 옆 반복 수를 정하고 생성 버튼을 누릅니다.
7. 결과 위 툴바에서 설정 불러오기, 그룹 추가, 프롬프트 복사와 다운로드 등을 사용하고 생성 이력에서 실패 메시지를 확인합니다.

## 로그인과 비용

이름이 표시된 NAI·Codex·ComfyUI·워크플로·예약 탭 옆에서 로그인 상태, 구독 티어, Anlas 잔액을 확인합니다. 관리자는 NAI 인증 창의 **설정에서 관리**로 설정 페이지를 열 수도 있습니다.

생성 버튼에는 가능한 경우 예상 비용이 표시됩니다.

생성 줄의 **…** 메뉴에는 채팅 프리셋 저장, 태그 정리(생성 도우미가 켜진 경우), 초기화 같은 보조 작업이 있습니다.

- 비용은 한 번 누를 때 넣는 작업 전체(작업 1개 예상 × 반복 수) 기준입니다.
- Opus 무료 조건은 작업마다 따지므로, 무료 조건이면 반복 수와 관계없이 무료로 표시됩니다.
- V5 모델의 무료 생성은 상단에 표시되는 Opus 사용량에서 차감됩니다. 사용량이 0%이면 같은 조건도 Anlas가 들므로 무료로 표시되지 않습니다. V4.5 이하 모델의 무료 생성에는 사용량 제한이 없습니다.
- 예상 비용은 NovelAI 웹 UI의 계산식을 따른 추정치입니다. V5 모델은 같은 조건에서 V4.5보다 1.5배 비쌉니다.
- 인핸스 Max는 서버 업스케일 비용을 미리 알 수 없어 `N+ Anlas`로 표시되고 무료로 표시되지 않습니다.
- 비용 계산 중이면 계산 상태가 표시됩니다.
- 로그인 전에는 생성 버튼이 비활성화됩니다.

## 프롬프트

| 항목 | 용도 |
| --- | --- |
| Prompt | 만들고 싶은 이미지 설명 |
| Negative Prompt | 피하고 싶은 요소 |
| Character Prompt | 캐릭터별 프롬프트/UC 분리 |
| AI's Choice | 캐릭터 위치를 NAI에 맡김 |
| 품질 태그 | 켜면 모델 권장 품질 태그를 프롬프트 뒤에 붙여 보냅니다. V5: `very aesthetic, masterpiece, no text` |
| UC 프리셋 | Heavy / Light / Human Focus 문구를 네거티브 프롬프트 앞에 붙여 보냅니다. 없음이면 붙이지 않습니다. |

캐릭터 위치를 직접 쓰면 보드에서 각 캐릭터의 위치를 지정할 수 있습니다. 지원하지 않는 모델에서는 캐릭터 프롬프트/위치 옵션이 비활성화됩니다.

품질 태그와 UC 프리셋은 기본으로 꺼져 있습니다. 문구는 NovelAI 웹 UI와 같고, 모델마다 다릅니다(마우스를 올리면 실제 문구가 보입니다). NAI Diffusion 3에는 없습니다. 이미 같은 문구를 직접 적어 쓰고 있다면 중복되지 않게 둘 중 하나만 쓰세요. V5의 Light / Human Focus 문구는 아직 웹 UI 요청으로 확인하지 못해 V4.5 Full 문구를 씁니다.

생성 도우미 플러그인을 켜면 자주 쓰는 태그 묶음을 프롬프트 아래에서 추가하고 입력할 수 있습니다. 레이아웃에서 블록을 직접 옮긴 경우에는 지정한 위치를 따릅니다. 플러그인을 잠시 꺼도 블록 위치와 숨김 설정은 보존되며 다시 켜면 돌아옵니다.

가중치 문법은 보낼 때 한 가지만 자동으로 맞춥니다. 숫자로 끝나는 태그 바로 뒤의 닫는 `::` 앞에 공백을 넣습니다(`1.5::artist:matrix16::` → `1.5::artist:matrix16 ::`). 그대로 보내면 NovelAI가 `16::`을 새 가중치로 잘못 읽기 때문입니다. 그 밖의 문법은 입력한 그대로 보냅니다.

## 캐릭터 라이브러리에서 불러오기

메인 프롬프트와 각 캐릭터 프롬프트 줄의 **캐릭터 불러오기**로 [외형 설정](CHARACTER_LIBRARY.md)을 골라 태그를 추가합니다. **캐릭터 불러와서 추가**는 새 캐릭터 프롬프트를 만듭니다. 값은 그때 복사하므로 이후 라이브러리 변경이 폼을 바꾸지는 않습니다.

기준 이미지는 캐릭터 레퍼런스 지원 모델에서만 함께 넣을 수 있습니다. 기본은 **새 참조로 추가**, 기존 참조가 있으면 **참조 k 교체 · 파일명**이나 **넣지 않기**를 고릅니다. 선택지가 하나일 때는 이미지 포함 스위치로 끕니다. 여러 캐릭터 레퍼런스는 NAI에서 섞여 사용되며 특정 캐릭터 프롬프트에 묶이지 않습니다.

설정 선택에는 `characters.view`, 이미지 옵션에는 `images.view`도 필요합니다.

## 주요 설정

| 설정 | 설명 |
| --- | --- |
| Model | NAI Diffusion 모델 선택. `V5 Full Medium (Economy)`는 V5 Full의 절약 모드입니다. |
| 생성 방식 | 새로 생성, 이미지 변형(img2img), 인페인트(infill) 중 작업 선택 |
| Sampler / Scheduler | 샘플링 방식과 스케줄러 |
| Steps | 생성 반복 수 |
| CFG Scale | 프롬프트 반영 강도 |
| Preset / Width / Height | 해상도 프리셋 또는 직접 입력 |
| Samples | 한 번에 생성할 이미지 수. 1~4 범위로 제한됩니다. |
| 반복 | 생성 버튼 한 번에 큐에 넣을 작업 수(1~32). |
| Seed | 재현용 시드. 비우면 랜덤입니다. |
| Variety+ | 지원 모델에서 변주 옵션을 사용합니다. |

### V5 절약 모드

`NAI Diffusion V5 Full Medium (Economy)`는 NovelAI 웹 UI의 Effort 토글이 쓰는 별도 모델(`nai-diffusion-5-full-medium`)로, V5 Full을 14스텝으로 줄인 저비용 모델입니다. 웹 UI와 같이 다음 값이 고정됩니다.

- 스텝 14, 샘플러 Euler Ancestral, Prompt Guidance Rescale 0
- 네거티브 프롬프트와 캐릭터 네거티브는 쓰지 않고 UC Heavy 문구만 보냅니다. 빼고 싶은 요소는 프롬프트에 `-2::hat::`처럼 음수 가중치로 적습니다.

품질 태그, Prompt Guidance, 시드는 바꿀 수 있고 img2img·인페인팅·인핸스도 됩니다. 다른 모델로 돌아가면 입력해 둔 스텝·샘플러·네거티브가 그대로 다시 쓰입니다.

### 반복 생성

반복 수만큼 같은 요청이 큐에 들어가고, 서버가 설정 → 생성 엔진 → 실행 간격에 있는 NovelAI 값(동시 실행, 구간당 생성 수, 최소 간격)에 맞춰 차례로 보냅니다. 와일드카드와 빈 시드는 작업마다 새로 정해집니다.

시드를 고정한 채 반복을 2 이상으로 하면 같은 이미지만 반복되므로 생성이 막힙니다. 프롬프트·네거티브·캐릭터 프롬프트에 랜덤 문법(`__이름__`, `++이름++`)이 있으면 허용됩니다.

## 이미지 작업

Action이 `generate`가 아니면 이미지 입력 영역이 열립니다.

| 작업 | 필요한 입력 |
| --- | --- |
| img2img | Source Image |
| infill | Source Image + Mask Image |

Source Image는 기존 이미지 기반 생성에 사용합니다.

Mask Image는 인페인트 영역을 지정합니다. 마스크는 내장 이미지 편집기에서 만들거나 별도 파일로 선택할 수 있습니다.

추가 옵션:

- Strength: 원본 이미지 유지/변형 강도. 인페인트에서는 마스크 영역을 다시 그리는 강도입니다. 작업을 infill로 바꾸면 웹 UI처럼 1에서 시작하고, img2img로 돌아가면 0.3이 됩니다(이후 직접 고칠 수 있습니다).
- Noise: 이미지 변형 노이즈
- Original: infill에서 원본 보존 옵션

### 인핸스 (강화 업스케일)

img2img에 원본 이미지를 넣으면 인핸스를 고를 수 있습니다. NovelAI 웹 UI의 Upscale Amount와 같습니다.

| 배율 | 동작 |
| --- | --- |
| 1x | 크기는 거의 그대로(64 배수로 맞춤) 두고 디테일만 다시 그립니다. 상한을 넘는 큰 원본은 64 배수로 내려 맞춥니다. |
| 1.5x | 원본을 NovelAI가 정한 강화 해상도로 키운 뒤 다시 그립니다(832×1216 → 1280×1856). 프롬프트 끝에 `-2::upscaled, blurry::,`가 붙습니다. |
| Max | 원본 크기에서 다시 그리고, NovelAI 서버가 결과를 약 3.1MP(1536×2048 픽셀 수)까지 키웁니다(832×1216 → 1467×2144). V5 모델 전용입니다. |

- 인핸스를 켜면 크기는 원본에서 정해지고, Strength / Noise는 웹 UI 기본값 0.5 / 0으로 바뀝니다(이후 직접 고칠 수 있습니다).
- 1.5x는 NovelAI 표준 크기에서만 쓸 수 있고, 결과가 상한을 넘는 Large·Wallpaper 크기에서는 막힙니다. 쓸 수 없는 배율은 이유와 함께 비활성화됩니다.
- 인핸스 결과는 이미지 저장 설정의 "저장 전에 크기 조정"을 건너뛰고 NovelAI가 돌려준 크기 그대로 저장됩니다. 저장 형식과 품질 설정은 그대로 적용됩니다.
- Max는 서버 업스케일 비용이 따로 들어 무료가 아닙니다. 1.5x는 결과가 1024×1024 픽셀 수를 넘으면 Anlas가 들고, 640×640·512×768 같은 작은 원본은 Opus 무료 조건에 들 수 있습니다. 생성 버튼의 예상 비용을 확인하세요.
- 기존 2x 업스케일 버튼(별도 업스케일러, 결과 다운로드)은 그대로 있습니다.

## 레퍼런스와 Vibe

### Character Reference

캐릭터 외형을 참고할 이미지를 추가합니다.

- 이미지 선택
- 타입 선택
- Strength 조정
- Fidelity 조정
- 자주 쓰는 레퍼런스 저장/불러오기

지원 모델에서만 활성화됩니다.

### Vibe

스타일·분위기를 참고할 이미지를 추가합니다.

- 이미지 선택
- Strength 조정
- Information Extracted 조정
- 저장된 Vibe 불러오기

Vibe 이미지는 생성 전 인코딩이 필요할 수 있습니다. 연결 상태가 끊기면 먼저 로그인 상태를 확인합니다.

NovelAI가 V5 모델용 Vibe Transfer를 아직 공개하지 않아, V5 모델에서는 Vibe를 추가할 수 없고 Vibe가 남아 있으면 생성이 막힙니다.

## 이미지 메타데이터의 모델

V5 이미지는 Full·Curated·절약 모드가 모두 Source `NovelAI Diffusion V5`를 쓰고 뒤의 8자리 해시만 다릅니다. CoNAI는 이 해시로 `NovelAI Diffusion V5 Full` / `V5 Curated` / `V5 Full Medium`을 구분해 표시하고, 모르는 해시는 `NovelAI Diffusion V5`로 둡니다. 이미 라이브러리에 있는 이미지는 메타데이터를 다시 읽을 때 반영됩니다.

## 결과 확인

생성 후 결과는 생성 이력 패널에 표시됩니다.

확인할 것:

- 성공/실패 상태
- 결과 이미지
- 저장 포맷과 리사이즈 적용 여부
- 재시도 가능 여부
- 업스케일 가능 여부

## 빠른 팁

- 일반 생성은 Prompt, Negative Prompt, Model, 해상도만 맞춰도 충분합니다.
- 여러 캐릭터는 Character Prompt로 분리합니다.
- 원본 이미지가 중요하면 Strength를 낮게 시작합니다.
- 재현이 필요하면 Seed를 고정합니다.
- 결과 저장 형식은 설정 → 미디어 처리 → 이미지 저장에서 관리합니다.
