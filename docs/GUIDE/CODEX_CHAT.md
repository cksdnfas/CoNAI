# Codex 채팅

서버에 연결된 Codex CLI와 대화하면서 CoNAI를 조작합니다. Codex는 CoNAI MCP 도구만 쓸 수 있어서, 이미지 검색·메타데이터 조회·NAI/ComfyUI/Codex 생성·워크플로우 실행·그룹 정리를 말로 요청할 수 있습니다.

## 위치

- **패널**: 상단 헤더의 채팅 아이콘을 누르면 어느 페이지에서든 오른쪽 패널로 열립니다. 휴대폰 폭에서는 전체 화면으로 열리고 뒤로가기로 닫힙니다.
- **전체 페이지**: `/#/chat`. 패널의 "전체 페이지로 열기"로 넘어가고, "패널로 접기"로 돌아옵니다. 왼쪽에 채팅 목록이 나옵니다.

설정에서 켜고 관리자 계정일 때만 헤더에 채팅 아이콘이 보입니다. 예전 주소 `/#/generation?tab=chat`은 `/#/chat`으로 넘어갑니다. 페이지를 옮기거나 패널과 전체 페이지를 바꿔도 진행 중인 답변은 끊기지 않습니다.

## 켜기

설정 → 생성 및 AI → **Codex 채팅**. 바꾼 값은 바로 적용됩니다.

| 항목 | 설명 |
| --- | --- |
| 채팅 사용 | 켜면 관리자에게 헤더의 채팅 아이콘이 보입니다. 기본값은 꺼짐입니다. |
| MCP 권한 | 채팅이 쓸 수 있는 도구 범위. 조회·생성·정리 중에서 고릅니다. 백업·복원은 채팅에 주지 않습니다. |
| 실행 모델 | Codex 에이전트 모델. 비우면 서버 CLI 기본 모델을 씁니다. |
| 추론 강도 | 선택한 모델이 지원하는 단계 중에서 고릅니다. 기본값은 서버 CLI 설정을 따르며, 지정하지 않았거나 해당 모델에서 지원하지 않는 기본 강도라면 모델의 기본 강도를 씁니다. 높을수록 응답 시간과 사용량이 늘어날 수 있습니다. |

실행 모델과 추론 강도는 채팅 입력창 아래의 선택 칸에서도 바꿀 수 있습니다. 설정 화면과 같은 **서버 공통 설정**이므로 다른 관리자의 채팅에도 적용됩니다. 모델을 바꿀 때 기존 추론 강도를 새 모델이 지원하지 않으면 기본값으로 돌아갑니다. 모델 목록을 가져오지 못하면 모델 직접 입력과 공통 추론 단계 선택을 제공하며, 실제 지원 여부는 Codex 실행 시 확인됩니다.

설정을 바꾸면 진행 중인 채팅 세션이 끊기고, 다음 메시지부터 새 설정으로 시작합니다. 기존 대화를 이어갈 때도 변경한 모델과 추론 강도가 적용됩니다. 현재 답변이 진행 중일 때는 채팅창의 설정 선택기가 잠깁니다.

사전 조건은 Codex 생성과 같습니다. 서버에 Codex CLI가 설치되어 있고 로그인되어 있어야 합니다. 자세한 내용은 [Codex 생성 → 사전 조건](./CODEX_GENERATION.md#사전-조건)을 참고합니다.

## 사용

1. 헤더의 채팅 아이콘으로 채팅을 엽니다.
2. 아래 입력창에 요청을 적고 Enter로 보냅니다. 줄바꿈은 Shift+Enter입니다.
3. 답변이 실시간으로 표시됩니다. Codex가 쓴 도구는 답변 위에 이름으로 나오고, 마우스를 올리면 결과 요약을 볼 수 있습니다.
4. 생성하거나 찾은 이미지는 답변에 썸네일로 나옵니다. PC에서는 마우스를 올리면 크게 미리 보이고, 누르면 페이지를 떠나지 않는 이미지 뷰어가 열립니다. 뷰어에서 같은 답변의 이미지를 ← →(휴대폰은 좌우로 밀기)로 넘기고, 더블클릭으로 원본 크기를 보고, 상세 보기·다운로드를 할 수 있습니다. ESC·뒤로가기·바깥 클릭으로 닫으면 채팅으로 돌아옵니다.
5. 답변 도중 중단 버튼으로 멈출 수 있습니다.

헤더의 **이미지 모아보기**는 이 채팅에 나온 이미지를 날짜별로 모아 보여 줍니다. **생성**(채팅에서 만든 이미지)과 **찾아본**(검색·조회로 본 이미지)으로 나눠 볼 수 있고, 뷰어의 "메시지로 이동"으로 그 이미지가 나온 답변으로 돌아갑니다. 목록은 저장된 대화에서 그때그때 만들기 때문에, 채팅을 지우면 함께 사라지고 이미지 자체는 라이브러리에 남습니다.

대화는 채팅별로 저장되고, 같은 채팅 안에서는 앞의 대화를 기억합니다. 페이지를 닫아도 진행 중인 답변은 서버에서 끝까지 진행되고 저장됩니다.

예:

```text
"풍경" 그룹에 있는 이미지 중 최근 것 5장 보여줘.
NAI로 비 오는 골목 일러스트 한 장 만들어서 "채팅 테스트" 그룹에 넣어줘.
```

## 할 수 있는 것과 없는 것

| 가능 | 불가능 |
| --- | --- |
| CoNAI MCP 도구 호출 (설정한 권한 안에서) | 셸 명령 실행 |
| | 서버 파일 읽기·쓰기 |
| | 웹 검색·브라우저 조작 |
| | 서버 Codex 설정에 등록된 다른 MCP 서버 사용 |

- 생성한 결과는 채팅한 관리자 계정의 생성 이력으로 기록됩니다.
- NovelAI 생성은 요청 한 번에 1장만 허용합니다. 2장 이상 동시 생성은 Anlas가 차감되므로, 여러 장이 필요하면 Codex가 요청을 나눠 보냅니다.
- 모든 사용자가 서버에 로그인된 Codex 계정 하나의 사용량을 함께 씁니다.

## 문제 해결

| 문제 | 확인 |
| --- | --- |
| 채팅 아이콘이 안 보임 | 설정에서 채팅 사용이 켜져 있는지, 관리자 계정인지 확인합니다. |
| 보내기 버튼이 비활성화됨 | 입력창 위에 Codex 로그인·설치 경고가 있는지 확인합니다. 로그인이 필요하면 생성 페이지의 Codex 탭에서 로그인합니다. |
| "셸 도구를 끌 수 없어" 오류 | 설치된 Codex CLI가 셸 차단 옵션을 지원하지 않는 버전입니다. CLI를 업데이트합니다. |
| 도구 호출이 실패함 | 설정의 MCP 권한에 필요한 범위(생성, 정리 등)가 켜져 있는지 확인합니다. |
