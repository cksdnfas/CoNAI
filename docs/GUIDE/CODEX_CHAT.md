# Codex 채팅

서버에 연결된 Codex CLI와 대화하면서 CoNAI를 조작합니다. Codex는 CoNAI MCP 도구만 쓸 수 있어서, 이미지 검색·메타데이터 조회·NAI/ComfyUI/Codex 생성·워크플로우 실행·그룹 정리를 말로 요청할 수 있습니다.

## 위치

`/generation?tab=chat` (생성 페이지 탭 맨 끝)

설정에서 켜고 관리자 계정일 때만 탭이 보입니다.

## 켜기

설정 → 생성 및 AI → **Codex 채팅**. 바꾼 값은 바로 적용됩니다.

| 항목 | 설명 |
| --- | --- |
| 채팅 사용 | 켜면 관리자에게 채팅 탭이 보입니다. 기본값은 꺼짐입니다. |
| MCP 권한 | 채팅이 쓸 수 있는 도구 범위. 조회·생성·정리 중에서 고릅니다. 백업·복원은 채팅에 주지 않습니다. |
| 실행 모델 | Codex 에이전트 모델. 비우면 서버 CLI 기본 모델을 씁니다. |

설정을 바꾸면 진행 중인 채팅 세션이 끊기고, 다음 메시지부터 새 설정으로 시작합니다.

사전 조건은 Codex 생성과 같습니다. 서버에 Codex CLI가 설치되어 있고 로그인되어 있어야 합니다. 자세한 내용은 [Codex 생성 → 사전 조건](./CODEX_GENERATION.md#사전-조건)을 참고합니다.

## 사용

1. 채팅 탭을 엽니다.
2. 아래 입력창에 요청을 적고 Enter로 보냅니다. 줄바꿈은 Shift+Enter입니다.
3. 답변이 실시간으로 표시됩니다. Codex가 쓴 도구는 답변 위에 이름으로 나오고, 마우스를 올리면 결과 요약을 볼 수 있습니다.
4. 생성하거나 찾은 이미지는 답변에 썸네일로 나오고, 누르면 이미지 상세로 이동합니다.
5. 답변 도중 중단 버튼으로 멈출 수 있습니다.

대화는 채팅별로 저장되고, 같은 채팅 안에서는 앞의 대화를 기억합니다. 페이지를 닫아도 진행 중인 답변은 서버에서 끝까지 진행되고 저장됩니다.

예:

```text
"풍경" 그룹에 있는 이미지 중 최근 것 5장 보여줘.
NAI로 비 오는 골목 일러스트 한 장 만들어서 "채팅 테스트" 그룹에 넣어줘.
```

## 할 수 있는 것과 없는 것

| 가능 | 불가능 |
| --- | --- |
| CoNAI MCP 도구 호출 (설정한 권한 안에서) | 셸 명령 실행 |
| | 서버 파일 읽기·쓰기 |
| | 웹 검색·브라우저 조작 |
| | 서버 Codex 설정에 등록된 다른 MCP 서버 사용 |

- 생성한 결과는 채팅한 관리자 계정의 생성 이력으로 기록됩니다.
- NovelAI 생성은 요청 한 번에 1장만 허용합니다. 2장 이상 동시 생성은 Anlas가 차감되므로, 여러 장이 필요하면 Codex가 요청을 나눠 보냅니다.
- 모든 사용자가 서버에 로그인된 Codex 계정 하나의 사용량을 함께 씁니다.

## 문제 해결

| 문제 | 확인 |
| --- | --- |
| 탭이 안 보임 | 설정에서 채팅 사용이 켜져 있는지, 관리자 계정인지 확인합니다. |
| 보내기 버튼이 비활성화됨 | 상단 상태가 `사용 가능`인지 확인합니다. 로그인이 필요하면 Codex 탭에서 로그인합니다. |
| "셸 도구를 끌 수 없어" 오류 | 설치된 Codex CLI가 셸 차단 옵션을 지원하지 않는 버전입니다. CLI를 업데이트합니다. |
| 도구 호출이 실패함 | 설정의 MCP 권한에 필요한 범위(생성, 정리 등)가 켜져 있는지 확인합니다. |
